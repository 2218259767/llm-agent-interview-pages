模型家族／Qwen（千问）系列

请介绍一下 Qwen3-VL，它和 Qwen2 相比有哪些改进？

约 4 分钟
更新于 2026-10-13

题目

请介绍一下 Qwen3-VL，它和 Qwen2 相比有哪些改进？

面试口述回答

Qwen3-VL 是千问的视觉语言模型，这里的视觉前代可以按 Qwen2-VL、Qwen2.5-VL 来比较。我会从信息流、时空表示和训练三方面介绍改进。

第一，DeepStack 把视觉编码器多个层级的特征，经 Merger 投影后加到语言模型前几层，让局部细节和高层语义都更充分地进入模型，对 OCR 和文档理解很有帮助。第二，Interleaved MRoPE 让时间、高、宽更均衡地使用不同频率，视频再用文本时间戳直接标记帧的位置，增强长视频理解和事件定位。

第三是视觉推理的后训练，包括 SFT、蒸馏和 RL。像数学数据会筛选真正需要看图才能解答的样本，让模型学会从视觉证据出发推理。我觉得这几项设计可以连起来理解：先把图看清楚，再对齐时空信息，最后训练模型怎样用这些信息解决问题。

详细知识笔记展开 / 收起

1. Qwen3-VL 是什么？

Qwen3-VL 是千问的视觉语言模型，可以理解文本、图像和视频，并生成文本回答。这里的问题沿用原文“和 Qwen2 比较”的说法，视觉部分的具体前代是 Qwen2-VL；中间的 Qwen2.5-VL 也在比较链路中。

模型主要由视觉编码器、视觉语言 Merger 和 Qwen3 语言主干构成。视觉编码器提取图像或视频帧特征，Merger 将视觉特征压缩并映射到语言模型的隐藏维度，语言模型再联合处理视觉与文本信息。

2. DeepStack：把多层视觉信息送入语言模型

前代主要通过视觉编码器末端的特征与语言模型对接。Qwen3-VL 增加跨层信息通路，从视觉编码器的三个层级取出特征，经各自 Merger 投影后，残差相加到 LLM 前三层对应的隐藏状态。

较早层和较深层包含不同层次的视觉信息，通过多条路径进入语言模型，可以同时利用局部细节和更高层语义。对于小字 OCR、图表和复杂文档，细节信息尤其重要。辅助特征使用相加融合，保持序列长度。

3. Interleaved MRoPE：更均衡地表示时间与空间

Qwen2-VL 的 MRoPE 将视觉位置拆成时间、高、宽三个轴。Qwen3-VL 采用 Interleaved MRoPE，在不同频率通道上交错分配三个轴，使时间和空间各自都覆盖高频、低频。

这样可以改善长视频中各轴频率分配不均的问题，让较近的空间变化和较远的时间关系都获得合适的表示。

4. 视频时间戳：直接用文本标记帧的时间

相对 Qwen2.5-VL 的时间对齐方式，Qwen3-VL 在视频帧组前增加文本时间戳，例如 <3.0 seconds>。模型因此能把画面与真实时间直接关联，支持事件定位、视频描述与时间相关问答。

报告模型原生训练窗口为 256K，并展示用 YaRN 扩展到 1M 的实验。长上下文、时间戳和位置编码共同服务于长文档与长视频理解。

5. 后训练与数据：让模型真正利用图像推理

后训练结合 SFT、蒸馏与 RL，分别增强视觉推理和通用交互能力。Reasoning RL 可以利用数学等任务的可验证答案；General RL 则结合任务规则或奖励模型处理更广泛的指令与描述任务。

原文重点提到的“多模态必要性过滤”用于视觉语言数学数据：先让纯文本基线尝试解题，保留更依赖图像证据的样本。这样能把训练重点放在观察图像、提取条件并完成推理的完整过程。

数据工程还包括多语言 OCR 的合成与标注，报告中的 OCR 语言覆盖扩展到 39 种，并强化文档理解以及物体位置、空间和功能信息。例如从“识别出一把椅子”扩展到“理解它可以坐、位于哪里”，为视觉 Agent 提供更丰富的环境表示。

6. 这些改动怎样联系起来？

DeepStack 改善视觉信息传入，Interleaved MRoPE 和时间戳改善时空关系表示，数据与后训练改善模型使用证据解决问题的能力。用“看清细节—对齐位置和时间—据此推理”来串联，会比孤立记三个技术名词更容易理解。

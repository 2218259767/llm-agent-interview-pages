模型后训练／RL 强化学习与偏好对齐

RL 如何提升大模型的推理能力？有哪些代表性研究？

追问约 13 分钟
更新于 2026-10-13
这道题接续什么是 Agentic RL？它怎样训练 Agent？

题目

强化学习提升推理能力，是提高已有解题路径的采样概率，还是学到了新的策略？可以结合哪些论文说明？

面试口述回答

我理解 RL 的一个重要作用，是通过探索发现高回报路径，再通过参数更新，让这些路径及其共通的决策模式更稳定地出现。预训练模型可能已经偶尔能做出很好的推理，RL 把这些低概率行为推向高概率区域，实际使用时就更容易在有限预算内成功。

这方面我会结合几类论文来讲。第一类是《Does RL Really Incentivize Reasoning Capacity Beyond the Base Model》，它在所测设置中发现，RL 模型小 k 表现更好，而基座在大 k 下能覆盖更多题，说明已有能力的调用效率很值得研究。第二类是《RLVR Implicitly Incentivizes Correct Reasoning》，它把中间推理也纳入 CoT-Pass@K，报告推理质量和可观测覆盖的改善。DeepSeek-R1 则给出了很直观的行为展示：通过 RL，模型出现了更强的反思、验证和策略调整。

再往 Agent 场景走，ARPO 研究工具交互后的不确定性、分支探索和优势归因，ReSearch 研究何时搜索、怎样查询、如何根据结果修正。这里的优化对象已经覆盖多步行动策略。我的判断方式是，先在相同预算下看成功率，再看大采样预算下的覆盖和中间过程；对 Agent，还要看工具成本与未见任务上的表现。这样就能具体说明，训练究竟把哪些潜在能力变得更稳定，又改进了哪些决策方式。

详细知识笔记展开 / 收起

1. 先把“RL 在挖掘模型潜力”拆成三个可以研究的问题

原笔记想解释的核心观点是：Agentic RL 通过与环境交互的 rollout 探索高回报轨迹，再通过策略优化提高这类轨迹及其共性决策模式的概率，把低概率、不稳定的潜在能力变成更稳定的行为。 理解相关论文时，可以沿着这句话的三个部分往下看：

  1. 模型怎样通过 rollout / exploration 找到高回报轨迹？
  2. policy optimization 怎样提高这些轨迹及其共性模式的概率？
  3. 提升具体体现在哪里：已有解题路径更容易出现、推理过程质量提高，还是形成了更有效的多步交互策略？

“把潜力拉出来并稳定化”是一个很有解释力的视角。预训练模型可能已经偶尔能解出一道题，只是这条路径在当前采样分布中概率很低；训练后，一次作答就走到这条有效路径的概率提高，模型的实际可用性也随之提高。进一步到 Agent 场景，模型还要学习怎样组合搜索、验证、反思和纠错，让这些能力在任务过程中配合起来。

下面按原笔记的三组论点展开七篇论文：先看推理分布怎样改变，再看哪些推理行为受到激励，最后看环境交互中的轨迹怎样被优化。

2. 高质量推理路径怎样变得更容易采样

Does Reinforcement Learning Really Incentivize Reasoning Capacity in LLMs Beyond the Base Model?

这篇论文直接研究“RL 是在提高已有能力的调用效率，还是扩大可解题范围”。它比较 RLVR 模型与对应基座在不同采样次数下的 pass@k：小 kkk 更接近日常少次生成的使用场景，大 kkk 则用更多尝试观察模型还能覆盖哪些题目。

论文在所测模型、任务与 RLVR 训练设置中发现，训练后的模型在小 kkk，尤其是 pass@1 上表现更好；当 kkk 足够大时，基座模型往往能覆盖更多题目。结合覆盖率与困惑度分析，作者据此认为，这些设置下的 RLVR 主要提高了基座已有高质量路径的采样效率。其论证链是：基座在大量尝试下已经能产生有效路径，RL 训练再把概率分布偏向这些更容易得到 reward 的路径。论文 v5

它对应原笔记里这句很直观的理解：把原本低概率、不稳定的潜在能力，变成更稳定、更高概率的行为。 从实用角度看，这个收益很大：用户通常只给模型有限次尝试，提高好路径的出现概率就能提升同样预算下的可靠性。讨论这篇时，最有价值的是讲清楚“采样效率”和“大预算下任务覆盖”这两个观察角度。

Reinforcement Learning with Verifiable Rewards Implicitly Incentivizes Correct Reasoning in Base LLMs

这篇进一步关注“正确答案背后的推理过程”。它重新考察 Pass@K，并引入 CoT-Pass@K，把最终答案与中间推理步骤一起纳入成功判定。作者在相应实验中报告 RLVR 能改善推理质量，并扩展数学、编程任务中的可观测推理边界；理论分析也讨论了为什么只依赖答案正确性的奖励，仍然能够隐式激励正确推理。论文 v2

这为原笔记中“通过策略优化提高这类轨迹及其共性决策模式的概率”增加了一层过程解释：学习信号给在最终结果上，但正确推理路径通常更容易持续产生正确结果，训练因而可以提升生成正确 reasoning 的倾向。看这个机制时，既要检查最终是否答对，也要检查模型怎样走到答案。

把前后两篇放在一起读很有价值：前一篇突出基座在大采样预算下的潜力，后一篇通过过程指标报告推理质量与覆盖的改善。它们提出了可继续检验的研究问题。比较时可以具体对齐基座、任务、训练算法、奖励、采样预算以及“成功”的判定方式，看结论差异与哪些设置相关。

3. RL 怎样激励反思、验证等推理行为

DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning

DeepSeek-R1-Zero 这条实验路线，从基座模型出发，直接通过大规模 RL 训练推理能力，省去预先的推理轨迹 SFT。训练过程中出现了自我反思、验证和策略调整等行为，展示了结果反馈可以怎样推动模型自己探索更有效的推理过程。DeepSeek-R1 v2

这篇在原笔记的论证里承担的是“行为变化的实践展示”：RL 确实能把推理、反思和验证激励出来，并使它们在任务中发挥作用。我们可以结合具体行为理解“把潜力转化为稳定策略”：模型遇到困难时花更多步骤分析，发现前面的假设不合适时回头修正，提交结论前增加一次检查。

其中最值得记住的是R1-Zero 的纯 RL 路线与完整 R1 的多阶段训练路线各自回答什么问题。前者展示探索与奖励对推理行为的激励，后者进一步结合冷启动数据和多阶段训练，改善综合表现。这样既能谈 RL 的作用，也能把它放回 SFT 与 RL 配合的训练流程。

Reinforcement Learning for Reasoning in Large Language Models with One Training Example

这篇研究 1-shot RLVR：使用一个训练题目，反复 rollout 并通过可验证奖励做 RL 更新，仍能在数学推理任务中获得显著收益。论文也观察到跨类别泛化、反思频率增加，以及训练准确率饱和后测试表现继续改善等现象，并强调探索在训练中的作用。论文 v3

原笔记由此提出一个推论：如果极少的训练题目就能把推理表现明显“拉出来”，这种提升很可能在利用预训练已经形成的能力，再通过反馈重塑它们的调用分布。这里的重点是，一个题目可以产生很多次尝试和不同轨迹，探索与策略更新仍然持续进行。训练题目少，与训练过程中能够获得多少探索经验，是两个可以分别分析的量。

这篇适合用来讨论“已有能力怎样被高效激励”。它让我们进一步思考：对于一个有较强预训练基础的模型，提供多少示范、选择什么训练问题、保留多少探索空间，分别影响训练的哪一部分。

4. 从数学 RLVR 走向 Agent：在环境交互中优化轨迹

前面的研究主要围绕推理与答案展开。原笔记中的关键词还有与环境交互：Agent 调工具后会收到新信息，需要根据观察继续做决策。因此，要理解 Agentic RL，需要接着看多轮工具、搜索与轨迹优化的研究。

Agentic Reinforced Policy Optimization（ARPO）

ARPO 观察到，模型在与外部工具交互之后，生成 token 的熵往往增加，意味着后续决策存在较高不确定性。它据此设计基于熵的自适应 rollout，在整条轨迹采样与步骤级采样之间动态分配探索，并结合优势归因估计，让模型学习不同工具交互步骤带来的收益差异。ARPO

这直接对应“在环境交互 rollout 中探索高回报轨迹”。例如，工具刚返回一批信息，模型接下来是继续查询、验证某条证据，还是直接回答，可能决定后半段任务走向。把探索集中到这类关键分支，就能比较不同后续选择的效果，再用优势信号更新策略。

它也让“高质量轨迹”这个概念更具体：一条成功轨迹由一系列决策组成，而工具返回后的某些步骤尤其值得探索和学习。于是，原笔记里的“共性决策模式”可以落到明确的对象上——在某类观察下，哪一种后续行动更有利于完成任务。

ReSearch: Learning to Reason with Search for LLMs via Reinforcement Learning

ReSearch 把搜索操作当作推理链的组成部分。模型通过文本推理决定什么时候搜、怎样构造查询，搜索结果又影响接下来的推理。训练依靠强化学习，使用过程中形成了反思和自我纠错等行为。ReSearch v3

这篇很适合解释原笔记所说的策略模式：什么时候先搜再想，什么时候根据搜索结果修正原假设，什么时候继续查询而不是直接回答。这些决策贯穿整个问题求解过程。比如新证据与原假设冲突时，Agent 需要调整后续路线；证据不足时，需要决定从哪个方向继续查。

把“搜索结果会改变后续推理”讲清楚，就能理解 Agentic RL 的学习对象：模型在新观察下怎样继续行动，以及这种行动怎样影响最终结果。相同的判断方式可以用于不同问题，这也是原笔记强调“把成功相关模式泛化出去”的原因。

R-Search: Empowering LLM Reasoning with Search via Multi-Reward Reinforcement Learning

R-Search 同样研究推理与搜索的交互，但更突出多阶段、多类型奖励对整条 reasoning-search trajectory 的联合优化。模型动态决定何时检索、何时继续推理，并把关键证据结合进后续过程，以改善复杂逻辑与知识密集任务的回答质量。R-Search

在原笔记的论证里，它补充的是“轨迹怎样被评价和优化”。Agent 的结果由多次推理与搜索共同产生，训练可以利用多个反馈信号来调整这个组合过程。这样讨论“高质量轨迹”时，就能从抽象的“多试几次、奖励好的”，进一步说到哪些搜索与推理决策需要反馈、整条路径应该怎样配合。

5. 把七篇论文放回同一个理解框架

这些论文分别解释了原观点的不同部分。探索并重加权高回报轨迹，可以结合 ARPO、ReSearch、R-Search 的交互与轨迹训练来讲；更稳定地复现成功相关的推理模式，可以结合 RLVR Implicitly Incentivizes Correct Reasoning 对过程质量的分析来讲；把基座中低概率的有效路径变得更常见，则可以结合 Does RL Really Incentivize Reasoning Capacity 的大 kkk 观察来讲。DeepSeek-R1 展示了训练中具体出现了哪些推理行为，1-shot RLVR 补充了少样本反馈如何激励已有基础能力的视角。

原笔记提出的整体理解可以保留下来：在不少 reasoning / RLVR 设置中，RL 的收益体现为对基座已有潜在高质量轨迹的重加权与稳定化；在 Agent 的多步工具交互中，反馈还可以塑造更有效的策略组织方式。 这把“潜力被激励”和“行动策略被优化”连在一起，也能自然解释为什么需要同时研究基座、探索、奖励、训练算法和环境。

6. 面试里怎样选择代表论文，实验里怎样形成自己的判断

原笔记给出的核心四篇很适合组织一次有层次的回答：先用 Does RL Really Incentivize Reasoning Capacity 说明已有分布与采样效率，再用 RLVR Implicitly Incentivizes Correct Reasoning 说明中间推理质量，接着用 DeepSeek-R1 说明训练中实际出现的反思和验证，最后用 ARPO 把讨论推进到多轮 Agent 交互。ReSearch、R-Search 可以展开搜索场景，1-shot RLVR 可以展开训练数据效率。

自己做实验时，我会先固定基座与推理预算，观察训练是否提高 pass@1，也就是一次生成的成功率；再扩大采样预算看 pass@k，检查在 kkk 次尝试中至少成功一次的任务覆盖情况。随后看推理步骤、验证和纠错过程是否正确，以及未见任务上的表现。对 Agent，还应记录环境观察、工具调用次数、行动成本与最终任务完成情况。

从实践角度，最直接的问题是：用同样的预算，模型是否更稳定地完成任务？ 进一步的分析则帮助我们弄清楚收益从哪里来，是原来少见的好路径更容易被采样到，还是推理质量、工具决策与纠错组织方式有所改善。按这样的顺序看证据，就能把论文讨论与实际训练目标联系起来。

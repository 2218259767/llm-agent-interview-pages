怎样讨论 RL 是激励已有能力还是带来新能力，论文证据有什么边界？

重点复习频率待统计约 4 分钟
更新于 2026-10-13·大模型算法 / 大模型 Infra / Agent 算法 / Agent 研发

题目

怎样讨论 RL 是激励已有能力还是带来新能力，论文证据有什么边界？

SPEAK WITH CLARITY · 面试表达

面试口述回答

我会先问这里的能力指 pass@1、较大 k 的覆盖率，还是未见任务与工具环境中的泛化。RL 提高成功轨迹概率是机制层面的解释，但它不等于已经证明只能重加权。现有论文存在分歧：有研究在其设置下观察到基座的大 k 覆盖边界，也有研究用过程指标报告推理边界改善。我的判断会同时看基座、训练和采样预算、奖励信息及过程正确性；对于 Agent，还要看是否学会更有效的交互策略，而不只是答案更流畅。

详细知识笔记展开 / 收起

先定义“新能力”是什么

单次回答准确率、较大采样预算下的 pass@k、推理过程正确率、未见任务泛化和工具使用策略，是不同指标。RL 后 pass@1 上升可以意味着成功轨迹更容易被采样，却不能独自证明能力边界扩大；反过来，有限采样没有找到某种行为，也不能证明基座对它的概率严格为零。

原笔记中的论文并非同一结论

研究与核验版本 可以支持的有限结论 不能直接推出
Does RL Really Incentivize…，v5 在其模型、算法与任务设置中，大 k 的覆盖分析支持基座能力边界的重要性 所有未来 RL 永远只能重加权
RLVR Implicitly Incentivizes…，v2 使用 pass@k 与 CoT-Pass@k，作者报告数学/代码推理边界及过程质量改善 它只是前一篇论文的同方向佐证
DeepSeek-R1，v2 纯 RL 可以激励可验证任务中的推理行为 单凭行为出现即可判定其在基座中绝不存在
One Training Example，v3 特定少样本 RLVR 设置能取得明显数学收益 任意一个样本都足够，或收益只来自记忆

原稿把这些工作整体描述为“向只是挖潜收敛”过于单向。论文的设置、评价指标与版本不同，回答时应保留分歧，而不是选取标题来支持预设观点。

Agent 论文讨论的是另一层

ARPO 关注工具交互后的不确定性、适应性 rollout 与优势归因；ReSearch 把搜索纳入推理过程；R-Search 用多种奖励优化推理与搜索轨迹。这些工作支持“交互策略值得直接优化”，并不单独证明新的参数知识如何产生。

本题核验了上述 7 篇论文的标题、版本和摘要层面的结论对应，不将其视为统一定理，也未独立复现其结果。更强的论证需要对齐基座、训练与推理预算、题目污染控制、过程判分和环境反馈可获得的信息。

面试中的立场

我的结论是条件化的：RL 改变行为分布，既可能提高已有成功路径的采样效率，也可能在特定评价下扩大可观测能力。实践上应报告可复现的能力变化，而不是用“挖潜”或“创造”替代实验。

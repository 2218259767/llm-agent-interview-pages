问答评估中的 Exact Match 和 Token F1 是什么？怎样计算？

约 5 分钟
更新于 2026-10-13

题目

问答评估中的 Exact Match 和 Token F1 是什么？怎样计算？

面试口述回答

Exact Match 和 Token F1 都是问答中常用的答案指标。先按数据集规则统一大小写、标点和空白等格式，EM 再检查预测与参考是否完全一致；Token F1 则统计重合词元，算出预测侧的精确率和参考侧的召回率，再取调和平均。比如参考是 President Richard Nixon，预测是 Richard Nixon，EM 为 0，但精确率是 1、召回率是三分之二，F1 是 0.8。有多个参考时，通常与各参考分别比较取最高分，再按题平均。我会用 EM 看完整命中，用 F1 看部分覆盖，同时固定文本处理规则；开放答案再补事实和证据评估。

详细知识笔记展开 / 收起

先统一答案的比较口径

问答评估常比较模型预测答案与人工参考答案。Exact Match（EM）检查标准化后的答案是否完全一致；Token F1 衡量两份答案在词元上的重合程度。 两者常用于实体、日期、短事实等答案比较明确的问答任务。

标准化规则由数据集约定。以 SQuAD 官方英文评测为例，先转为小写，去除指定标点和英文冠词 a/an/the，再合并多余空白；随后按空白切分 token。这里的 token 是评测用的文本单位。中文任务应固定采用的数据集分词或按字规则，使各模型在相同口径下比较。

Exact Match 怎样计算

设标准化函数为 N(⋅)N(\cdot)N(⋅)，预测答案为 ppp，参考答案为 ggg，则

EM(p,g)=1[N(p)=N(g)].\mathrm{EM}(p,g)=\mathbf{1}[N(p)=N(g)].EM(p,g)=1[N(p)=N(g)].

完全匹配得 1，其余得 0。例如预测 The Eiffel Tower、参考 Eiffel Tower，经过上述英文规则处理后都成为 eiffel tower，因此 EM 为 1。这个指标适合观察完整答案命中的比例。

Token Precision、Recall 和 F1

先统计预测和参考中各 token 的出现次数。重合数 mmm 是每种 token 在两侧出现次数的较小值之和，因此重复词按实际次数参与匹配。设预测包含 npn_pnp​ 个 token，参考包含 ngn_gng​ 个 token，则

P=mnp,R=mng,F1=2PRP+R.P=\frac{m}{n_p},\qquad R=\frac{m}{n_g},\qquad F_1=\frac{2PR}{P+R}.P=np​m​,R=ng​m​,F1​=P+R2PR​.

Precision 表示预测中有多少内容被参考覆盖；Recall 表示参考中有多少内容被预测覆盖。F1 用调和平均同时考虑两者，遗漏答案内容会降低 Recall，多写无关内容会降低 Precision。

例如参考是 President Richard Nixon，预测是 Richard Nixon。标准化后分别有 3 个和 2 个 token，重合数为 2，因此 P=1P=1P=1、R=2/3R=2/3R=2/3、F1=0.8F_1=0.8F1​=0.8，EM 为 0。F1 在这里保留了部分答案正确的信息。

没有重合 token 时 F1 为 0。SQuAD 2.0 将无答案表示为空字符串：预测和参考都为空时 F1 为 1，仅一侧为空时为 0；其无答案概率阈值另行决定何时提交空答案。

多个参考答案与数据集汇总

同一问题可能有多种可接受答案，例如简称、全称或人工标注的不同表达。SQuAD 对每个参考分别计算 EM 和 F1，然后各自取最高分。预测命中任一可接受参考，便可得到相应分数。

最终先得到每道题的 EM 和 F1，再分别对题目取算术平均，通常乘 100 展示。这样每道题贡献相同权重，长答案的词数不会改变该题在总体平均中的权重。

怎样结合任务使用

EM 适合检查严格的完整命中，F1 适合分析部分覆盖和冗余。两者都依赖参考答案与文本处理规则，因此评估前应补齐常见别名、固定标准化流程，并抽查高分与低分案例。

开放式长答案还应检查事实、逻辑、信息覆盖和证据支持；涉及否定、实体关系或数字单位时，使用相应的语义或规则校验。对于搜索 Agent，可以把答案 EM/F1 与检索证据支持率放在一起看，分别观察答案质量和搜索是否有效。

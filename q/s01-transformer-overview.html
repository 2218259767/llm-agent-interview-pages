基础模型架构／Transformer

请介绍一下 Transformer 的整体架构和各个组件的作用。

约 5 分钟
更新于 2026-10-13

题目

请介绍一下 Transformer 的整体架构和各个组件的作用。

面试口述回答

Transformer 是以注意力机制为核心的序列模型。原始结构由 Encoder 和 Decoder 组成：Encoder 双向读取输入，生成上下文表示；Decoder 一边读取已经生成的目标前缀，一边通过 Cross-Attention 访问 Encoder 的输出。

拆开一个 Block，Attention 负责在 token 之间聚合信息，多头让它从多个投影空间建立联系；FFN 负责逐位置的非线性加工；残差提供信息和梯度通路，归一化帮助稳定训练。位置编码补充词序，因果 Mask 保证生成时按照从左到右的顺序使用信息。

现在常见的 Decoder-only 把条件和回答放进同一条序列，用因果注意力持续预测下一 token。我理解 Transformer 的关键是：用 Attention 建立灵活的信息联系，同时把训练组织成适合大规模并行的矩阵计算。

详细知识笔记展开 / 收起

1. 整体结构：Encoder 编码输入，Decoder 生成输出

Transformer 是以注意力机制为核心的序列模型。原始论文针对机器翻译，采用 Encoder–Decoder 架构：Encoder 将源句子编码成一组上下文表示，Decoder 根据目标句子的前缀和 Encoder 输出，逐个生成目标 token。

文本先经过分词得到 token ID，再查 Embedding 表得到向量。若 batch 大小为 BBB、序列长度为 TTT、隐藏维度为 DDD，输入表示的形状为 [B,T,D][B,T,D][B,T,D]。接下来加入位置信息，再送入多层 Transformer Block。

2. Self-Attention：让 token 读取相关上下文

同一份隐藏状态经过三组投影得到 Query、Key、Value。可以把 Query 理解为“当前位置想找什么”，Key 是“各位置提供什么线索”，Value 是“真正取回的信息”。先用 Q 与 K 计算匹配程度，再对 V 加权求和：

Attention⁡(Q,K,V)=softmax⁡(QK⊤dk+M)V.\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V.Attention(Q,K,V)=softmax(dk​​QK⊤​+M)V.

dkd_kdk​ 是每个注意力头的 Key 维度，MMM 表示可见位置的限制。多头注意力使用多组投影，分别建立不同的信息联系，再把各头输出拼接、投影回隐藏维度。例如同一个“苹果”，在水果和手机语境下会从不同上下文提取信息。

3. FFN、残差与归一化

FFN 对每个 token 的隐藏状态独立做非线性变换。原始形式是先升维、激活，再降维：

FFN⁡(x)=σ(xW1+b1)W2+b2.\operatorname{FFN}(x)=\sigma(xW_1+b_1)W_2+b_2.FFN(x)=σ(xW1​+b1​)W2​+b2​.

Attention 完成位置之间的信息聚合，FFN 加工聚合后的特征。现代大模型常使用 SwiGLU 等门控 FFN，也会把部分 FFN 扩展成 MoE。

残差连接将子层输入直接加回输出，为信息和梯度提供较短路径。归一化控制表示的数值尺度，帮助深层网络优化。原始 Transformer 是 Post-Norm；Llama、Qwen 等常用 Pre-Norm 和 RMSNorm。

4. 位置编码与 Mask

Attention 的匹配计算需要位置信息，才能表达词序。原始 Transformer 将正弦位置向量加到输入 Embedding；RoPE 则在每层注意力中旋转 Q、K，把相对距离放进匹配分数。

Encoder 使用双向 Self-Attention，真实源 token 之间可以互相访问。Decoder 的 Self-Attention 使用因果 Mask，让当前位置读取自身和之前的目标 token。Decoder 随后通过 Cross-Attention 读取源序列：Q 来自 Decoder，K/V 来自 Encoder 输出。Padding Mask 用来屏蔽补齐位置。

5. 与现代 Decoder-only 的联系

Decoder-only 将系统指令、用户问题和回答组织成同一条序列，使用因果 Self-Attention 和 FFN 堆栈，最后通过 LM Head 预测下一 token。它把多种任务统一为条件生成，便于预训练、微调和推理复用同一条数据流。

Transformer 训练时能把已知序列的多个位置一起计算，矩阵运算适合 GPU 并行；Attention 也让远距离 token 之间建立直接联系。这两点是它适合大规模训练的重要原因。

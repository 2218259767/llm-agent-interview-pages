基础模型架构／Transformer

请介绍一下 Transformer 的整体架构和各个组件的作用。

约 16 分钟
更新于 2026-10-19

题目

请介绍一下 Transformer 的整体架构和各个组件的作用。

面试口述回答

首先从整体上看，原始 Transformer 是一个 Encoder–Decoder 架构。Encoder 把源 token 序列编码成一组上下文相关的向量表示；Decoder 根据这组表示和目标前缀，逐步生成输出。

首先说 Encoder。假设输入 token ID 张量的形状是 [batch_size,src_len]，经过 Token Embedding 查表，再加入位置编码，变成 [batch_size,src_len,d_model]。其中每个位置对应一个 d_model 维向量。经过 Encoder 后，长度和隐藏维度保持不变，但每个位置已经融入了其他有效位置的上下文信息。

Encoder 由多个 Block 堆叠。每个 Block 主要有多头 Self-Attention 和 FFN 两个子层。Self-Attention 的 Q、K、V 都来自该层输入，分别通过不同的线性投影得到，用来计算各 token 的关联并聚合信息；多头在不同表示子空间中建立联系。FFN 对每个 token 独立进行非线性加工，原始 base 模型使用 512→2048→512，中间是 ReLU。

每个子层外都有残差连接和 LayerNorm。原始结构是先将子层输出与输入相加，再归一化，也就是 Post-Norm。残差有助于信息和梯度传播，归一化帮助稳定训练。

接下来说 Decoder。每个 Decoder Block 有三个子层：带因果掩码的多头 Self-Attention、Cross-Attention 和 FFN，也分别配有残差与归一化。因果掩码让目标位置只读取已有前缀；Cross-Attention 的 Query 来自目标侧前一个子层的结果，Key 和 Value 来自 Encoder 最终输出，使 Decoder 能结合源句信息生成。

以翻译为例，源序列长度和目标序列长度可以不同。Encoder 输出 [batch_size,src_len,d_model]，Decoder 隐藏状态按目标长度排列，最后通过线性层和 Softmax 得到下一 token 的概率。训练时使用右移的真实目标序列，推理时使用已经生成的前缀。现在的 Decoder-only 模型则主要保留因果 Self-Attention 和 FFN 堆栈，把条件与回答组织成同一序列来预测下一 token。

详细知识笔记展开 / 收起

1. 整体架构与 Encoder 表示

原始 Transformer 是用于序列到序列任务的 Encoder–Decoder 模型。Encoder 把源 token 序列编码成一组连续的上下文表示；Decoder 结合这组源序列表示和目标前缀，自回归地生成输出。这里限定“原始 Transformer”，后续的 Encoder-only、Decoder-only 是不同架构形态。

设 batch 大小为 B，源序列在 batch 内 Padding 后长度为 S，模型隐藏维度为 D。离散输入是形状 [B,S] 的 token ID 张量。Token Embedding 查表得到 [B,S,D]，加入位置信息后通过 Encoder Blocks，最终仍输出 [B,S,D]。

单个样本的输出是 S×D 矩阵：保留 S 个位置，每个位置有一个 D 维隐藏向量。更准确的表述是“将源 token 序列编码为一组上下文相关的向量表示”。这与把整句话压成一个 D 维句向量是不同的数据结构；句向量可以另用 Pooling 或指定位置提取。

区分两个阶段：Token Embedding 为同一个 token ID 取同一行基础向量；Encoder 输出会随可见上下文和位置而变化。例如“苹果很好吃”与“苹果发布了手机”中的“苹果”，基础查表向量相同，经过上下文编码后的隐藏状态可以不同。每个位置的表示能够聚合其他有效位置的信息。

你的翻译例子可以直接保留：源输入为 [B,S]，Encoder 最终隐藏状态 H_enc 为 [B,S,D]；目标长度 T 由目标序列决定，可以与 S 不同。这里的 H_enc 也常称为 Encoder memory，供每层 Decoder 的 Cross-Attention 读取。原论文 §3.1 将 Encoder 输出定义为连续表示的序列。原始论文

2. Token Embedding 与位置编码

Token Embedding 参数表为 E∈R^(V×D)，V 是词表大小。token ID 为 20 时读取 E[20]，即索引为 20 的那一行，采用从零编号时是第 21 行。整个 batch 的查表过程是 [B,S]→[B,S,D]。PyTorch 的 Embedding 就是这种索引查表模块。Embedding 官方文档

原始 Transformer base 取 D=d_model=512，这是具体模型配置；不同模型可以选择其他隐藏维度。原论文使用固定的正弦、余弦位置编码，与 token 向量逐元素相加，而不是把二者拼接，维度仍为 [B,S,D]。严格对应原论文输入时，还对 Token Embedding 乘以 sqrt(D)，再加入位置编码并施加 Dropout。

可以说“输入表示由 Token Embedding 和 Positional Encoding 共同组成”。Positional Encoding 是更通用的术语：原论文默认使用的正弦编码由公式生成；另有学习式位置 Embedding。原因是纯 Self-Attention 的内容匹配自身没有标明第几个位置，需要显式的位置信息来表达词序，例如区分“我爱你”和“你爱我”。

3. Encoder Block：Self-Attention、Add & Norm、FFN

原始模型的 Encoder 由 N=6 个 Block 堆叠，各层结构相同、参数各自训练。一个 Block 包括两个子层：多头 Self-Attention 和逐位置 FFN。每个子层外都有残差连接和 LayerNorm。

Self-Attention 中，Q、K、V 的输入来源相同，都是该层输入 X；真正参与点积与加权计算的 Q、K、V 由各自的可学习投影得到：

Q=XWQ,K=XWK,V=XWV.Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V.Q=XWQ​,K=XWK​,V=XWV​.

忽略 batch 与多头的维度展开，注意力计算为：

Attention⁡(Q,K,V)=softmax⁡(QK⊤dk+M)V.\operatorname{Attention}(Q,K,V) =\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V.Attention(Q,K,V)=softmax(dk​​QK⊤​+M)V.

Q 表示“当前位置在找什么”，K 提供匹配线索，V 是取回并加权聚合的信息。多头分别投影到不同表示子空间，在各头计算后拼接，再投影回 D 维。Encoder 中有效的源位置可双向互相访问，Padding Mask 排除补齐位置；注意力跨位置聚合信息。你的“把同一层输入同时送给 Q/K/V”在模块接口意义上成立，要补清内部不同的投影。MultiheadAttention 官方文档

你口述的 Add 与 Norm 顺序需要调换。原始 Transformer 是 Post-Norm：先计算子层输出，和原输入做残差相加，再 LayerNorm。忽略 Dropout，整个 Encoder Block 是：

U=LN⁡1(X+MHA⁡(X,X,X)),U=\operatorname{LN}_1\bigl(X+\operatorname{MHA}(X,X,X)\bigr),U=LN1​(X+MHA(X,X,X)),
Y=LN⁡2(U+FFN⁡(U)).Y=\operatorname{LN}_2\bigl(U+\operatorname{FFN}(U)\bigr).Y=LN2​(U+FFN(U)).

两处 LayerNorm 的参数各自独立。实现时原模型先在子层输出施加 Dropout，再相加归一化。残差使子层学习在已有表示上做增量修正，并为信息和梯度提供较直接的传播路径，有助于训练更深的网络；LayerNorm 调整各位置隐藏表示的尺度与偏移，帮助优化。TransformerEncoderLayer 官方文档 的 norm_first 参数区分先归一化与后归一化，默认对应后者。

FFN 是同一层对各 token 分别应用、参数共享的非线性变换。原始 base 配置为 512→2048→512，中间用 ReLU：

FFN⁡(x)=max⁡(0,xW1+b1)W2+b2.\operatorname{FFN}(x)=\max(0,xW_1+b_1)W_2+b_2.FFN(x)=max(0,xW1​+b1​)W2​+b2​.

你的 512→1024→512 是合法的自定义 FFN 宽度；若介绍原论文，应改为 2048。它仅改变每个位置的特征，临时升维后降回 D，因此 Block 前后的 [B,S,D] 一致。Attention 负责在 token 之间聚合信息，FFN 负责逐位置的非线性加工。原论文 §3.3 与官方参考层的默认中间维度相互核对一致。

原笔记还用“加工与记忆”解释 FFN，这个直觉保留为有来源的研究视角：Transformer Feed-Forward Layers Are Key-Value Memories 将 FFN 解释为键值记忆，研究了模式匹配与输出分布的对应。这支持 FFN 参数承担记忆与变换作用的理解；本题用逐位置非线性加工解释其架构职责，知识如何分布在整网中另按具体研究分析。

4. Decoder Block：因果 Self-Attention 与 Cross-Attention

Decoder 同样从目标侧 token Embedding、位置编码进入多层 Block，每层有三个子层：Masked Multi-Head Self-Attention、Cross-Attention、FFN。每个子层按原论文采用残差相加后 LayerNorm。

第一层注意力需要强调“Masked”：目标侧每个输入位置可以读取自身和此前的位置，通过因果掩码屏蔽后续位置。结合训练时目标输入右移一位，每个位置用已有前缀预测下一个目标 token。Padding Mask 与因果 Mask 处理不同问题：前者去掉补齐位置，后者限制未来可见性。MultiheadAttention 的 masks

你的 Cross-Attention 来源判断正确。设当前 Decoder Block 的因果 Self-Attention 经 Add & Norm 后为 U，最后一层 Encoder 输出为 H_enc，则：

Q=UWQ,K=HencWK,V=HencWV.Q=UW_Q,\qquad K=H_{\mathrm{enc}}W_K,\qquad V=H_{\mathrm{enc}}W_V.Q=UWQ​,K=Henc​WK​,V=Henc​WV​.

这里 Q 来自目标侧当前子层的输入，K/V 来自最终 Encoder 输出，并分别做该层的投影；并非把 K 和 V 当成完全相同的计算结果。它让 Decoder 在生成目标内容时，按当前需求读取源句。

源长度为 S、目标输入长度为 T 时，每头的匹配分数是 [B,T,S]，含 h 个头时为 [B,h,T,S]；在源位置维度上归一化并加权后，Cross-Attention 的输出仍按目标位置排列，合并多头后的形状为 [B,T,D]。因此 S 与 T 可以不同。三子层可简写为（忽略 Dropout）：

U=LN⁡1(X+MaskedMHA⁡(X,X,X)),U=\operatorname{LN}_1\bigl(X+\operatorname{MaskedMHA}(X,X,X)\bigr),U=LN1​(X+MaskedMHA(X,X,X)),
C=LN⁡2(U+MHA⁡(U,Henc,Henc)),C=\operatorname{LN}_2\bigl(U+\operatorname{MHA}(U,H_{\mathrm{enc}},H_{\mathrm{enc}})\bigr),C=LN2​(U+MHA(U,Henc​,Henc​)),
Y=LN⁡3(C+FFN⁡(C)).Y=\operatorname{LN}_3\bigl(C+\operatorname{FFN}(C)\bigr).Y=LN3​(C+FFN(C)).

这里 MHA 表示模块级输入，内部仍有 Q/K/V 投影。Encoder 的完整源序列通常已知，所以翻译任务的 Cross-Attention 可以访问所有有效源位置。

5. 输出、训练与生成的连接

Decoder 最终输出为 [B,T,D] 的隐藏状态，再经线性输出层得到 [B,T,V_tgt] 的词表 logits，经 Softmax 可得到下一目标 token 的概率分布。这补齐了“从目标侧隐藏状态到实际生成 token”的路径。

你讲“Decoder 输入 Target Sequence”时，要补上训练与推理的条件：训练时用右移的真实目标序列，已知前缀允许多个目标位置在因果掩码下并行计算；推理时输入起始标记和已经生成的目标前缀，逐步生成到结束。你本次已讲出的源端 [B,S]→[B,S,D] 路径及源目标不等长例子全部保留，完整逐步数据流在第 2 题继续由你口述。原始论文 §3.1、§3.4

6. 与已有笔记中现代模型的联系

原始模型和现代 Decoder-only 要分清。已有笔记中的联系保留，以 LLaMA 1 报告的 §2.2 为明确例子：采用 Pre-Norm、RMSNorm、SwiGLU 和各层 RoPE。Decoder-only 通常保留因果 Self-Attention 与 FFN 堆栈，通过 LM Head 做下一 token 预测，用同一序列组织条件和回答；原始翻译 Decoder 读取 Encoder 的 Cross-Attention 不在这类基本架构中。

RoPE 在注意力中对 Q/K 加入旋转的位置结构，区别于原始输入端相加的位置编码；MoE 可以扩展 FFN 部分。相关原理在本批已选后续题目展开。本题主线仍按你的顺序介绍原始 Encoder–Decoder，然后用一句话连接现代结构。LLaMA 1 原始报告 §2.2、RoFormer §3.2、Switch Transformers

Transformer 用注意力直接联系远距离位置；在已知序列的训练计算中，各位置的注意力与逐位置变换可用并行矩阵运算。这是原笔记中“信息联系与大规模并行计算”两层解释的保留，生成阶段仍按自回归依赖逐步得到新 token。

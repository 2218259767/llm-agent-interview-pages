为什么语言模型的 Transformer 通常使用 LayerNorm，而不是 BatchNorm？

追问约 11 分钟
更新于 2026-10-19
这道题接续请介绍一下 Transformer 的整体架构和各个组件的作用。

题目

为什么语言模型的 Transformer 通常使用 LayerNorm，而不是 BatchNorm？

前置主问：请介绍一下 Transformer 的整体架构和各个组件的作用。

面试口述回答

要回答这个问题，我会先从深度学习中为什么需要归一化讲起。归一化可以帮助控制隐藏表示的数值尺度、改善优化条件，让深层网络的训练更加稳定。从数学上看，它的核心操作是将一组数减去均值，再除以标准差，实际使用时通常还会加上可学习的缩放和平移。BatchNorm 和 LayerNorm 最关键的区别，就是选取哪些数来计算这些统计量。

假设 Transformer 中一批 token 的隐藏状态形状是 BatchSize×SequenceLen×EmbeddingDim，那么 LayerNorm 就是在每个 token 对应的 EmbeddingDim 个特征上计算均值和方差，并在这个 token 内部进行归一化。

至于 BatchNorm，可以先看 CNN 中的情况。CNN 的隐藏张量通常是 BatchSize×Channel×Height×Width。BatchNorm 按通道分别计算统计量：每个通道汇总 BatchSize×Height×Width 个值。如果有 10 个通道，就计算 10 组均值和方差，再分别归一化。

如果把这种方式迁移到 NLP，将 EmbeddingDim 作为通道数，那么就会针对每个特征维度，跨 BatchSize 和 SequenceLen 计算统计量。也就是说，共有 EmbeddingDim 组统计量，每组使用 BatchSize×SequenceLen 个值。

在具体应用中，我主要从三个方面理解 Transformer 为什么更适合 LayerNorm。

首先，Transformer 会在序列内部建模 token 之间的语义关系，并形成每个位置的隐藏表示。如果使用 BatchNorm，当前 token 的归一化结果就会受到同 batch 中其他句子、其他位置的统计量影响。而 LayerNorm 的归一化统计只依赖当前 token 自己的特征，不额外引入跨样本、跨位置的统计依赖，更适合逐 token 的表示处理。

其次，LayerNorm 在训练与推理时使用相同的统计规则。BatchNorm 默认在训练时使用当前 batch 的统计量，在推理时使用训练期间累计的运行均值和方差。我之前看到过相关研究：如果不同 batch 的统计量波动较大，当前统计与累计统计就可能出现明显差异。而 LayerNorm 在训练和推理时，都根据当前 token 的隐藏向量计算均值和方差。

最后，LayerNorm 更容易处理变长序列和 Padding。未经额外处理的 BatchNorm 会把 Padding 位置也纳入统计，进而影响有效 token 的归一化结果；LayerNorm 在每个 token 内部独立统计，Padding 位置的数值不会混入其他 token 的归一化统计。

详细知识笔记展开 / 收起

1. 归一化的目的与计算

归一化帮助控制隐藏表示的数值尺度、改善优化条件，使深层网络更容易稳定训练。梯度传播还受残差、初始化、网络结构等因素影响，不能将归一化单独写成防止全部梯度问题的充分条件。

常见归一化先选定一组数，减去均值、除以标准差，再施加可学习的缩放和平移：

y=γ⊙x−μσ2+ϵ+β.y=\gamma\odot\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta.y=γ⊙σ2+ϵ​x−μ​+β.

其中 gamma/beta 是可学习参数，epsilon 保证数值稳定。BN 与 LN 的关键区别是计算均值、方差的统计范围。关于归一化帮助优化的措辞，用 How Does Batch Normalization Help Optimization? v5 的研究作为依据；该论文研究的是 BN 的优化性质，本题不把其理论直接扩展为所有归一化的统一定理。

2. Transformer 中的 LayerNorm

一批 token 的隐藏状态形状为 [B,T,D]，B 是 batch 大小、T 是序列长度、D 是隐藏维度。常见 LayerNorm(D) 固定样本 b 和位置 t，在 X[b,t,:] 的 D 个特征上计算统计量：

μb,t=1D∑d=1DXb,t,d,σb,t2=1D∑d=1D(Xb,t,d−μb,t)2.\mu_{b,t}=\frac1D\sum_{d=1}^{D}X_{b,t,d},\qquad \sigma^2_{b,t}=\frac1D\sum_{d=1}^{D}(X_{b,t,d}-\mu_{b,t})^2.μb,t​=D1​d=1∑D​Xb,t,d​,σb,t2​=D1​d=1∑D​(Xb,t,d​−μb,t​)2.

每个 token 各自计算均值、方差；同一 LN 模块的 gamma/beta 为 D 维参数，在不同样本与位置之间共享。形状 [B,T,D] 不变。原论文的每样本内部统计思想与 PyTorch normalized_shape=D 的定义相互印证。LN 原论文 v1、LayerNorm main 文档

这里的隐藏状态本身已经可以通过 Attention 包含其他位置的上下文信息；“只看当前 token”专指 LN 的统计范围，而非该 token 的表示没有上下文。

3. 从 CNN 中的 BatchNorm 迁移到 NLP

CNN 隐藏张量通常为 [B,C,H,W]，BatchNorm2d 为每个通道分别汇总 B×H×W 个值计算均值、方差。如果 C=10，就计算 10 组均值、方差，并用各通道自己的统计量归一化。BatchNorm2d main 文档

将类似统计方式用于 NLP 的 [B,T,D]，将 D 作为通道数，例如在 PyTorch 中转成 [B,D,T] 后使用 BatchNorm1d(D)。每个隐藏特征通道汇总 B×T 个值，得到 D 组统计量。BatchNorm1d main 文档

方式 固定对象 统计范围 均值/方差组数
LN(D)，输入 [B,T,D] 每个样本、每个 token D 个特征 B×T
CNN BN2d，输入 [B,C,H,W] 每个通道 B×H×W 个值 C
序列 BN1d，输入 [B,D,T] 每个特征通道 B×T 个值 D

例如，B=2、T=2、D=3，四个 token 向量分别为 [1,2,3]、[4,5,6]、[101,102,103]、[104,105,106]。LN 为每个向量单独统计，第一行均值为 2；序列 BN 按通道统计，第一个特征汇总 [1,4,101,104]，均值为 52.5。这是人为构造的统计示例，不是真实词向量。

4. Transformer 的三点选型理由

第一，统计依赖范围与逐 token 表示的匹配。 Transformer 在序列内建模 token 之间的语义联系，并形成每个位置的隐藏表示。跨 B×T 的 BN 会让当前 token 的归一化结果依赖其他样本与位置的统计。LN 在每个 token 内部统计，其归一化统计与同 batch 中其他句子的组成无关。这里的机制是跨样本与位置的统计依赖，不能仅由语义不同本身推导 BN 必然不适用。

第二，训练与推理的统计规则。 默认 BN 训练时使用当前 batch 的统计量，同时累计运行均值与方差；评估时使用累计的统计量。LN 在两个阶段都根据当前 token 计算统计量。使用 Rethinking Batch Normalization in Transformers v1 §III 核验“其 NLP Transformer 实验存在明显 batch 统计波动、当前统计与运行统计差异”这一技术主张。论文属于该机制的独立经验依据，不将其具体实验泛化为任何任务的固定性能排名。

第三，变长与 Padding。 直接跨 B×T 统计的普通 BN 若没有额外排除 Padding，补齐位置也会参与均值与方差，影响真实 token；LN 的每个有效 token 只使用自己的 D 个特征，Padding 位置的数值不会混入其统计。例如，某个通道有效值 [2,4] 均值为 3，若加入两个值为 0 的 Padding，未做排除的统计均值变为 1.5。这里由普通 BN 统计轴推导出的实现后果，明确标作推论。Attention 的 Padding Mask 仍用于约束注意力读取。

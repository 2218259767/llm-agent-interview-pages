Attention 计算中为什么要除以 √d_k？

追问约 5 分钟
更新于 2026-10-13
这道题接续请介绍一下 Transformer 的整体架构和各个组件的作用。

题目

Attention 计算中为什么要除以 √d_k？

面试口述回答

因为 Query 和 Key 的点积尺度会随头维度增大。做一个初始化近似：各维零均值、单位方差且相互独立时，每个乘积项方差为 1，d_k 项相加后方差就是 d_k。除以 √d_k，方差就回到常数量级。

如果直接把尺度很大的分数送进 Softmax，注意力容易过早集中到个别位置，Softmax 的局部梯度会变小，训练更难。平方根缩放能够维持适合优化的分数范围；如果除以 d_k，又会让初始分数过度收缩。这里的 d_k 指的是每个头的维度。

详细知识笔记展开 / 收起

1. 这个缩放发生在哪里？

缩放点积注意力先算 Query 与 Key 的点积，再除以每个头维度的平方根，最后通过 Softmax 得到权重：

Attention⁡(Q,K,V)=softmax⁡(QK⊤dk)V.\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V.Attention(Q,K,V)=softmax(dk​​QK⊤​)V.

dkd_kdk​ 是单个注意力头的 Key 维度。缩放的目的是让点积分数在头维度增大时仍保持适合优化的尺度。

2. 从点积方差推导

在初始化的简化分析中，假设 qi,kiq_i,k_iqi​,ki​ 相互独立，均值为零、方差为一，各维乘积彼此不相关。先看单项乘积的均值。利用独立性，乘积的期望可以拆开：

E[qiki]=E[qi]E[ki]=0.\mathbb E[q_i k_i]=\mathbb E[q_i]\mathbb E[k_i]=0.E[qi​ki​]=E[qi​]E[ki​]=0.

再从方差定义 Var⁡(X)=E[X2]−(E[X])2\operatorname{Var}(X)=\mathbb E[X^2]-(\mathbb E[X])^2Var(X)=E[X2]−(E[X])2，算出两个变量的二阶矩：

E[qi2]=Var⁡(qi)+(E[qi])2=1+02=1,E[ki2]=Var⁡(ki)+(E[ki])2=1.\begin{aligned} \mathbb E[q_i^2]&=\operatorname{Var}(q_i)+(\mathbb E[q_i])^2=1+0^2=1,\\ \mathbb E[k_i^2]&=\operatorname{Var}(k_i)+(\mathbb E[k_i])^2=1. \end{aligned}E[qi2​]E[ki2​]​=Var(qi​)+(E[qi​])2=1+02=1,=Var(ki​)+(E[ki​])2=1.​

由于 qiq_iqi​ 和 kik_iki​ 独立，qi2q_i^2qi2​ 与 ki2k_i^2ki2​ 也独立，因此 E[qi2ki2]=E[qi2]E[ki2]\mathbb E[q_i^2k_i^2]=\mathbb E[q_i^2]\mathbb E[k_i^2]E[qi2​ki2​]=E[qi2​]E[ki2​]。代回乘积的方差：

Var⁡(qiki)=E[(qiki)2]−(E[qiki])2=E[qi2]E[ki2]−02=1⋅1=1.\begin{aligned} \operatorname{Var}(q_i k_i) &=\mathbb E[(q_i k_i)^2]-(\mathbb E[q_i k_i])^2\\ &=\mathbb E[q_i^2]\mathbb E[k_i^2]-0^2\\ &=1\cdot1=1. \end{aligned}Var(qi​ki​)​=E[(qi​ki​)2]−(E[qi​ki​])2=E[qi2​]E[ki2​]−02=1⋅1=1.​

点积是 dkd_kdk​ 项之和，因此

Var⁡(q⊤k)=∑i=1dkVar⁡(qiki)=dk.\operatorname{Var}(q^\top k)=\sum_{i=1}^{d_k}\operatorname{Var}(q_i k_i)=d_k.Var(q⊤k)=i=1∑dk​​Var(qi​ki​)=dk​.

利用 Var⁡(X/c)=Var⁡(X)/c2\operatorname{Var}(X/c)=\operatorname{Var}(X)/c^2Var(X/c)=Var(X)/c2，可以得到

Var⁡(q⊤kdk)=1.\operatorname{Var}\left(\frac{q^\top k}{\sqrt{d_k}}\right)=1.Var(dk​​q⊤k​)=1.

这给出了平方根缩放的依据：头维度越大，原始点积标准差越大；除以平方根，将分数尺度保持在常数量级。

3. 分数过大会怎样影响 Softmax？

较大的分数差会让 Softmax 集中到少数位置，分布接近 one-hot。Softmax 的导数是

∂pi∂zj=pi(δij−pj).\frac{\partial p_i}{\partial z_j}=p_i(\delta_{ij}-p_j).∂zj​∂pi​​=pi​(δij​−pj​).

当某个概率接近 1、其余概率接近 0 时，这些局部导数都很小，注意力分数获得的梯度变弱。缩放让训练初期的注意力分布保持合适的敏感度，便于模型逐步学出该关注的位置。

4. 为什么选平方根？

如果直接除以 dkd_kdk​，同一统计假设下方差会变成 1/dk1/d_k1/dk​，头维度很大时，初始分数会过度集中在零附近，Softmax 更接近均匀分布。除以 dk\sqrt{d_k}dk​​ 则在维度变化时维持常数量级。训练过程中，投影权重继续学习分数分布，QK-Norm 等设计进一步控制 Q/K 的尺度。

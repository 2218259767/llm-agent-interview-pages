Attention 计算中为什么要除以 √d_k？

追问约 10 分钟
更新于 2026-10-20
这道题接续请介绍一下 Transformer 的整体架构和各个组件的作用。

题目

缩放点积注意力为什么要除以根号下 d_k？

面试口述回答

缩放点积注意力首先让 Query 和 Key 做点积，计算注意力分数。在多头实现中，就是将 Key 的最后两个维度转置，再和 Query 做矩阵乘法，其中 d_k 是单个注意力头的 Key 维度。

我们做一个简化的统计假设：q 和 k 各维元素相互独立，均值为 0、方差为 1。那么，每个乘积 q_i k_i 的方差为 1，d_k 项相加后，点积的方差就是 d_k。因此，随着头维度增大，注意力分数的波动尺度也会增大。

如果这些分数之间的差距过大，Softmax 就容易进入饱和区域，输出接近 one-hot：一个权重接近 1，其他权重接近 0。这时 Softmax 对注意力分数的局部导数会很小，包括那个概率接近 1 的位置，因为它的导数包含 p(1-p)。这样，传回 Query 和 Key 的梯度容易变弱，影响注意力分配的学习。

所以，我们在 Softmax 前将点积除以根号下 d_k。根据方差的性质，随机变量除以一个常数，方差就除以这个常数的平方，因此缩放后的方差是 d_k 除以 d_k，等于 1。这样可以抵消点积尺度随维度的增长，减轻 Softmax 过早饱和的问题，让训练更容易进行。

详细知识笔记展开 / 收起

1. 点积与缩放发生在哪里

缩放点积注意力先用 Query 和 Key 的点积得到分数，在 Softmax 前除以单个头的 Key 维度的平方根：

Attention⁡(Q,K,V)=softmax⁡ ⁣(QK⊤dk)V.\operatorname{Attention}(Q,K,V) =\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V.Attention(Q,K,V)=softmax(dk​​QK⊤​)V.

在多头张量表示中，例如 Q 为 [B,H,T_q,d_k]，K 为 [B,H,T_k,d_k]，对 K 的最后两维转置后，矩阵乘法得到 [B,H,T_q,T_k]。QK 点积沿最后的特征维求和，所以决定这一求和尺度的是 d_k。Softmax 沿 Key 位置维计算，将一行分数变为对各个 Key 的注意力权重。原论文 §3.2.1–3.2.2

d_k 指单个注意力头的 Key/Query 维度。在原始 Transformer 的多头设置中，模型宽度为 512、头数为 8，每头 d_k=64。分析的重点是随着 d_k 增大，点积方差会增长，因此按头维度做缩放；模型总宽度与每头宽度应分别理解。原论文 §3.2.2

2. 方差推导的统计前提

先取某一个 Query 向量 q 和某一个 Key 向量 k，点积分数为它们 d_k 项对应元素乘积之和。在一个简化统计模型中，假设各元素是独立随机变量，均值为 0、方差为 1。更具体地说，单项 q_i 与 k_i 独立，并且不同维的乘积项互不相关，就足以用于下面的方差相加。

这是用于解释初始化附近分数尺度的统计假设。实际 Q/K 由隐藏状态经学习得到的线性投影产生，均值、方差与相关性会随数据和训练变化。前面的 LayerNorm 约束的是其输入/输出对应的特征统计；后续投影产生的 Q/K 使用这里的近似分析，而非由“做过归一化”直接推出所有独立性条件。原论文 §3.2.1 脚注与 §3.2.2

原论文的独立、零均值、单位方差假设，与 D2L 官方教材对点积尺度的独立推导相符。D2L 1.0.3 §11.3.1

3. 从单项乘积到整个点积：保留完整推导

点积定义为：

z=q⊤k=∑i=1dkqiki.z=q^\top k=\sum_{i=1}^{d_k}q_i k_i.z=q⊤k=i=1∑dk​​qi​ki​.

先计算单项乘积的均值。由 q_i 与 k_i 独立，期望可以拆开：

E[qiki]=E[qi]E[ki]=0.\mathbb E[q_i k_i]=\mathbb E[q_i]\mathbb E[k_i]=0.E[qi​ki​]=E[qi​]E[ki​]=0.

从方差定义出发，单位方差和零均值给出两个二阶矩：

E[qi2]=Var⁡(qi)+(E[qi])2=1,E[ki2]=Var⁡(ki)+(E[ki])2=1.\begin{aligned} \mathbb E[q_i^2] &=\operatorname{Var}(q_i)+(\mathbb E[q_i])^2=1,\\ \mathbb E[k_i^2] &=\operatorname{Var}(k_i)+(\mathbb E[k_i])^2=1. \end{aligned}E[qi2​]E[ki2​]​=Var(qi​)+(E[qi​])2=1,=Var(ki​)+(E[ki​])2=1.​

q_i 与 k_i 独立，因而它们的平方也独立。代回单项乘积的方差：

Var⁡(qiki)=E[qi2ki2]−(E[qiki])2=E[qi2]E[ki2]−02=1.\begin{aligned} \operatorname{Var}(q_i k_i) &=\mathbb E[q_i^2 k_i^2]-(\mathbb E[q_i k_i])^2\\ &=\mathbb E[q_i^2]\mathbb E[k_i^2]-0^2\\ &=1. \end{aligned}Var(qi​ki​)​=E[qi2​ki2​]−(E[qi​ki​])2=E[qi2​]E[ki2​]−02=1.​

各维乘积互不相关时，和的方差等于方差之和，所以：

E[z]=0,Var⁡(z)=∑i=1dkVar⁡(qiki)=dk.\mathbb E[z]=0,\qquad \operatorname{Var}(z) =\sum_{i=1}^{d_k}\operatorname{Var}(q_i k_i)=d_k.E[z]=0,Var(z)=i=1∑dk​​Var(qi​ki​)=dk​.

因此，未缩放点积的方差随 d_k 线性增长，标准差为根号下 d_k。这里讨论的是分数的典型波动尺度；随着维度增大，同一行分数更容易出现较大的差值。原论文 §3.2.1 脚注、D2L §11.3.1

4. Softmax 饱和怎样影响注意力分数的梯度

Softmax 把一行分数 z 映射为概率 p。分数之间的差距很大时，分布可能过早变得非常尖锐：某一位置的权重接近 1，其他位置接近 0。这里说的是接近 one-hot 的饱和状态。原论文 §3.2.1

从 Softmax 定义求导，可得局部 Jacobian：

∂pi∂zj=pi(δij−pj).\frac{\partial p_i}{\partial z_j} =p_i(\delta_{ij}-p_j).∂zj​∂pi​​=pi​(δij​−pj​).

其中，i=j 时为 p_i(1-p_i)，i≠j 时为 -p_i p_j。当最大概率 p_a 接近 1 时，它自己的导数 p_a(1-p_a) 也接近 0；其他概率接近 0，相关的对角与交叉导数同样接近 0。因此，经注意力 Softmax 传回分数的梯度容易变弱，模型难以有效调整 Q/K 对应的注意力分配。

例如只有两个位置，概率为 [0.9999,0.0001]，最大概率位置对自身分数的导数也只有 0.9999×0.0001≈0.0001。并非因为它的概率大，就会在这一位置积累更大的 Softmax 局部梯度。

用会议类比理解：注意力权重过度集中，像会议中一个人的声音占主导，聚合结果几乎只采用他的 Value；而模型若要重新调整“该听谁”，还要经过 Softmax 对分数的导数。这条调整注意力的路径在饱和时变弱。Value 的加权路径与 Q/K 经过分数和 Softmax 的路径应分别理解。这里的 Jacobian 与示例是根据 Softmax 定义直接求导的解释，与原论文“小梯度区域”的描述相符。

5. 除以根号下 d_k 怎样改变方差

方差对常数缩放满足：

Var⁡(X/c)=Var⁡(X)c2.\operatorname{Var}(X/c)=\frac{\operatorname{Var}(X)}{c^2}.Var(X/c)=c2Var(X)​.

因此，在上述统计假设下：

Var⁡ ⁣(q⊤kdk)=dk(dk)2=1.\operatorname{Var}\!\left(\frac{q^\top k}{\sqrt{d_k}}\right) =\frac{d_k}{(\sqrt{d_k})^2}=1.Var(dk​​q⊤k​)=(dk​​)2dk​​=1.

缩放点积在进入 Softmax 前消除随头维度增长的尺度因素，使初始分数保持常数量级，减轻注意力分布过早饱和、分数梯度过小的问题。方差等于 1 是在该假设下推导出的结果；对实际训练，它提供的是与维度相匹配的尺度控制。原论文 §3.2.1、D2L §11.3.1

6. 为什么平方根比直接除以 d_k 更合适

比较两种缩放方式：如果直接除以 d_k，同样的假设下得到：

Var⁡ ⁣(q⊤kdk)=dkdk2=1dk.\operatorname{Var}\!\left(\frac{q^\top k}{d_k}\right) =\frac{d_k}{d_k^2}=\frac{1}{d_k}.Var(dk​q⊤k​)=dk2​dk​​=dk​1​.

头维度越大，初始分数会越集中在 0 附近，Softmax 更接近均匀分布；除以根号下 d_k 则在维度变化时维持常数量级，保留分数区分度。这是同一统计模型下对两种缩放方式的比较。模型训练中投影权重继续学习分数分布；直接约束 Q/K 尺度的 QK-Norm 等机制也可作为相关设计继续理解。

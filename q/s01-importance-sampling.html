什么是重要性采样？它在 PPO、GRPO 中有什么作用？

约 3 分钟
更新于 2026-10-13

题目

请介绍重要性采样的基本原理，并结合 PPO、GRPO 和 GSPO 解释新旧策略概率比的作用。

面试口述回答

重要性采样是用一个分布产生的样本，估计另一个分布下的期望，做法是给样本乘上目标概率与采样概率的比值。PPO、GRPO 需要它，是因为回答由旧策略生成，而同一批数据会被当前策略重复用于更新。优势告诉我们这个行动值不值得鼓励，概率比修正新旧策略的相对权重。随着策略变化，权重方差会变大，所以还需要裁剪和定期重新采样。长回答下，token 级和序列级比率的选择会影响稳定性，这也是 GSPO 改用长度归一化序列比率的背景。

详细知识笔记展开 / 收起

用一个分布的样本估计另一个分布的期望

假设想计算目标分布 PPP 下的平均值，却只能从分布 QQQ 采样。只要 P(x)>0P(x)>0P(x)>0 的地方也有 Q(x)>0Q(x)>0Q(x)>0，可以通过概率比重新加权：

Ex∼P[f(x)]=Ex∼Q[P(x)Q(x)f(x)].\mathbb E_{x\sim P}[f(x)]=\mathbb E_{x\sim Q}\left[\frac{P(x)}{Q(x)}f(x)\right].Ex∼P​[f(x)]=Ex∼Q​[Q(x)P(x)​f(x)].

P(x)/Q(x)P(x)/Q(x)P(x)/Q(x) 就是重要性权重。目标分布中更常见、采样分布中更少见的样本得到较大权重；反向情形则得到较小权重。

例如采样数据过度包含高个子人群时，直接计算平均身高会偏高。知道两个群体的分布后，可以降低过度采样群体的权重，提高采样不足群体的权重。

为什么策略训练需要概率比

大模型生成一批回答成本较高，因此常先用旧策略采样，再对当前策略做多次更新。数据来自 πold\pi_{\mathrm{old}}πold​，优化对象却是 πθ\pi_\thetaπθ​，概率比提供了修正这种差异的依据。

PPO 和 GRPO 的常见 token 比率是：

ρt=πθ(yt∣x,y<t)πold(yt∣x,y<t).\rho_t=\frac{\pi_\theta(y_t\mid x,y_{<t})}{\pi_{\mathrm{old}}(y_t\mid x,y_{<t})}.ρt​=πold​(yt​∣x,y<t​)πθ​(yt​∣x,y<t​)​.

策略目标将 ρt\rho_tρt​ 与优势 AtA_tAt​ 相乘。优势决定应鼓励还是抑制该行动；概率比反映它在新旧策略下的相对权重。训练初始两者相同时，比率为 1；随着更新，概率比逐渐偏离 1。

为什么需要裁剪和刷新样本

当新旧分布差距变大，少数样本的权重可能很大，估计方差上升。PPO 风格的裁剪目标限制这些样本继续推动策略大幅变化，改善训练稳定性。有限次数更新后重新采样，也让行为数据继续贴近当前策略。

完整轨迹的概率比由所有 token 比率相乘，长序列容易形成很大的数值变化。GSPO 使用长度归一化的序列比率，让一条回答共享更新尺度；详细公式见 GSPO。

面试中讲清两个量

优势描述回答好不好，概率比描述新旧策略对该回答的相对概率。 两者共同作用。比较方案时，重点观察策略差距、概率比的分布、裁剪比例和有效样本利用率。

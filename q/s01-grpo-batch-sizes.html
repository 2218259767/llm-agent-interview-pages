GRPO 训练中的几种 batch size 分别是什么意思？

追问约 4 分钟
更新于 2026-10-13
这道题接续什么是 GRPO？请介绍它的原理。

题目

在 GRPO 训练中，rollout batch、group size、mini-batch 和单卡 micro-batch 分别控制什么？它们与梯度累积有什么关系？

面试口述回答

GRPO 里要先区分采样和更新两个阶段。Rollout batch 决定一轮采多少个问题，group size 决定每题生成几个回答；mini-batch 决定一次优化器更新汇总多少数据；micro-batch 决定每张卡一次前后向吃下多少数据，剩余部分通过梯度累积完成。例如 4 张数据并行卡，每卡 2 条回答，累积 4 次，就形成 32 条回答的一次更新。我会先统一 prompt、回答和 token 的计数口径，再调显存和吞吐，避免把不同层次的 batch 混在一起。

详细知识笔记展开 / 收起

先看一次 GRPO 训练经历哪两个阶段

在 GRPO 中，先采样回答并评分，再用这批回答更新策略。因此要分别说明“收集多少数据”和“每次参数更新处理多少数据”。

名称 含义 主要影响
rollout/train batch 一轮采样选择的 prompt 数 BBB 任务覆盖与刷新频率
group size 每个 prompt 采样的回答数 GGG 组内奖励比较与生成成本
mini-batch 一次优化器更新汇总的样本量 梯度统计、每批更新次数
micro-batch per GPU 每卡一次前后向处理的样本量 mmm 激活显存与硬件利用
gradient accumulation 更新前累计多少次梯度 aaa 把多个 micro-batch 合成一次更新

用统一计数口径算一遍

假设一轮有 16 个 prompt，每题采 4 个回答，就得到 64 条回答。若一个 mini-batch 含 32 条回答，则一轮数据对应 2 次优化器更新。

若有 4 个数据并行设备，每卡每次处理 2 条回答，累计 4 次梯度，则一次更新的有效回答数为：

Bupdate=NDP×m×a=4×2×4=32.B_{\mathrm{update}}=N_{\mathrm{DP}}\times m\times a=4\times2\times4=32.Bupdate​=NDP​×m×a=4×2×4=32.

其中 NDPN_{\mathrm{DP}}NDP​ 是数据并行数量。采用张量并行时，总 GPU 数还要按并行方式划分。多轮优化同一批 rollout，会进一步增加更新次数。

对照实际框架参数

原笔记中的 verl 参数包括 data.train_batch_size、ppo_mini_batch_size、ppo_micro_batch_size_per_gpu。这些名称分别对应数据采样、优化批次与单卡执行粒度；阅读配置时同时确认是否按 prompt 计数、是否在内部乘了每题回答数，以及是否启用了按 token 动态组批。

怎样调节

显存不足时，先减小单卡 micro-batch 或控制每卡 token 数，再用梯度累积保持目标更新批量。吞吐不足时，观察 GPU 利用率、通信和最长序列，调整 micro-batch 与组批策略。梯度噪声较大时，再结合数据覆盖调整有效更新批量。rollout batch 和 group size 则要一起权衡任务多样性、组内对比质量与采样时间。

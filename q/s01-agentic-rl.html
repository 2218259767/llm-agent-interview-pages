什么是 Agentic RL？它怎样训练 Agent？

约 9 分钟
更新于 2026-10-13

题目

请介绍 Agentic RL 的基本原理：Agent 的轨迹包含什么，rollout、奖励和策略更新怎样配合？

面试口述回答

Agentic RL 是用强化学习训练 Agent 在多步任务中的行动策略。模型先在环境里做 rollout，探索不同的规划、搜索、工具调用和纠错路径，再根据任务反馈计算优势、更新参数，让高回报路径以及其中共通的决策模式更容易出现。

我会把它理解成“把潜力转化为稳定策略”。预训练模型可能已经会一些推理、规划和自我修正，但这些行为出现得不稳定。RL 一方面把低概率的好策略推到高概率区域，另一方面通过长期回报，把这些能力重新编排：什么时候应该补搜、什么时候值得花成本验证、失败后怎样换一条路。这对 Agent 很有价值，因为多步任务通常存在多种成功路径，逐步标注最优示范很难，而最终任务结果往往更容易评价。

可以打个比方：一边探索，一边定义什么算金子，一边训练自己更会淘。对应到训练，就是探索覆盖、奖励设计、信用分配和稳定优化要配合起来。我会固定推理预算，比较训练前后的成功率与调用成本，再看未见任务上的表现，判断这些偶尔成功的行为是否已经变成稳定能力。

详细知识笔记展开 / 收起

1. 核心过程：找到高回报轨迹，让它以后更容易出现

Agentic RL 的核心之一，是让模型先通过大量 rollout / exploration 采样出不同轨迹，其中一部分轨迹的结果更好，然后用 RL 的更新规则，让模型以后更倾向于生成这些“高回报轨迹”。

可以先用一句直观的话抓住它：找到了高质量的轨迹，然后通过参数更新来增加这类高质量轨迹出现的概率。 在这个过程中，模型学习的是自己在什么情境下应当采取什么行动，以及这些行动怎样共同通向最终成功。

对 Agent 来说，一条轨迹包含整个任务过程：想什么、先做什么、调哪个工具、查哪类信息、是否回溯、是否分解任务，以及最后如何组织答案。给定任务和已有观察，模型决定下一步是规划、检索、调用工具、检查结果、修正方案还是提交答案；环境返回的新信息又影响后续决策。

一条轨迹可以写成 τ=(s1,a1,r1,…,sT,aT,rT)\tau=(s_1,a_1,r_1,\ldots,s_T,a_T,r_T)τ=(s1​,a1​,r1​,…,sT​,aT​,rT​)：sts_tst​ 表示决策时使用的上下文与观察历史，ata_tat​ 是模型采取的行动，rtr_trt​ 是相应反馈。在只有终局奖励的任务中，前面的 rtr_trt​ 可以为零，直到任务结束后才得到成功与否的评价。

2. 重塑策略分布：把“通向成功的决策模式”泛化出去

RL 调整的是模型的行为策略：提高产生高回报行为的概率，降低产生低回报行为的概率，并让相似情境下“通向成功的决策模式”更容易被调用。这里的学习对象可以表述为：哪类思考路径、行动顺序、工具使用方式、搜索策略，更容易得到高回报。

以资料检索任务为例，一条成功轨迹里可能包含“先拆分问题，再查权威来源，遇到冲突后补搜，证据充分时停止”。训练希望强化的是这些决策与情境之间的联系：查询过宽时换关键词，证据不足时补搜，信息冲突时核对来源，证据充分时结束。这样遇到新问题时，模型也能运用类似的判断方式。

因此，Agentic RL 优化的对象可以更准确地说成：模型在一个多步决策过程中的行为策略。 一条轨迹是这种策略的一次展开，而训练会改变以后很多次展开的分布。

3. 为什么可以把 RL 理解成“挖掘模型的潜力”

预训练模型里常常已经隐含了不少能力：会推理一点、会规划一点、会调用工具一点，也会自我修正一点。实际使用时，这些能力可能在原始采样分布里不稳定、不常出现、不会系统性触发。同一道题，模型偶尔能找到一条很好的路径，但大多数时候会过早回答、沿着错误假设继续走，或者漏掉一次关键验证。

RL 做的事情常常是：从大量 rollout 里找到这些“偶尔闪现的高质量行为”，再通过训练把它们变成更高概率、更稳定的行为。从这个角度看，确实像是在把原来潜在的好策略，从低概率区域往高概率区域推出来。

这也解释了为什么“能偶尔做对”和“能稳定做对”之间有很大的实用差别。部署时只有有限的时间、token 和工具调用预算，模型需要更经常地在这些预算内走到有效路径。提高好策略的出现概率，就能把潜在能力转化成日常使用中的可靠表现。

4. 进一步的价值：把已有能力重新编排、强化、固化

在多步 Agent 任务中，反馈还可以推动模型形成更有效的策略组织方式。推理、搜索、验证、纠错这些能力如何组合，往往直接决定任务结果。原笔记提出的“重新编排、强化、固化”，强调的就是这一层。

例如，为最终成功而放弃眼前看起来最顺畅的选择：模型已经有一个似乎合理的答案，但先花一次工具调用核实关键事实，可能更有利于最后交付。又如，第一次搜索没有找到证据时，先分析哪里出了问题，再改写查询和试探另一条路径。通过回报与优势信号，这类多步试探、纠错和反思可以得到强化，模型也有机会学会更合适的探索与利用节奏。

这里涉及长程信用分配（credit assignment）：最后成功了，前面哪些决策起了作用？最后失败了，应该调整哪一步？训练算法需要把后续回报关联到前面的行动，让那些暂时增加成本、却有利于最终成功的选择也能得到有效学习信号。

5. 为什么 Agent 场景适合这种学习方式

SFT 更像是告诉模型“标准示范长这样”；Agentic RL 更像是让模型自己试很多次，然后强化“哪种行动路径最终能赢”。SFT 可以示范完整的工具使用与决策过程，RL 则让模型在自身实际走出的路径上接收结果反馈。两者的详细比较见 SFT 和 RL 有什么区别？应该怎样选择？。

很多 Agent 任务需要连续搜索、试错、调工具、中间决策、长链路规划，以及根据反馈修正。每一步写出最优示范既昂贵，也容易遗漏其他有效做法；而任务最后是否完成、证据是否充分、操作是否成功，往往更容易评价。RL 可以利用最终结果给整条轨迹提供学习信号，再通过回报估计、基线或步骤级归因，把信号传递给具体行动。

例如，同一个资料检索任务可能有多条成功路径。我们希望模型学会根据自己已经拿到的信息决定下一步，并逐渐减少无效搜索、重复调用和过早结束。这样的目标天然覆盖整个交互过程。ReSearch 把搜索融入推理链，ARPO 则进一步研究工具交互后的探索与优势归因。

6. Rollout、反馈、优势估计与策略更新怎样配合

一次完整的训练循环包括四步：

  1. Rollout：当前策略在环境中执行任务，采集不同解题路径。探索决定模型能见到哪些结果，也为比较路径提供候选。
  2. 反馈：通过任务验证器、环境结果或质量评分，评价最终成功和过程表现；同时可计入调用成本、耗时和无效操作。
  3. 优势估计：结合奖励与基线，判断哪些行为相对更值得强化；多步任务还要把后续回报分配给前面的动作。
  4. 策略更新：提高高优势行动的概率，降低低优势行动的概率，再用更新后的模型继续采样。新的策略会改变下一轮能探索到的轨迹。

若采用策略梯度，其直观形式为：

∇θJ≈E[∑tAt∇θlog⁡πθ(at∣st)].\nabla_\theta J\approx\mathbb E\left[\sum_t A_t\nabla_\theta\log\pi_\theta(a_t\mid s_t)\right].∇θ​J≈E[t∑​At​∇θ​logπθ​(at​∣st​)].

AtA_tAt​ 表示行动相对基线的好坏；它为正时，该行动的概率受到正向推动。PPO、GRPO 等方法在此基础上加入各自的优势估计和更新控制。这样，原来“探索到一次成功”的经验就通过参数更新影响后续行为。

7. “一边探索，一边定义什么算金子，一边训练自己更会淘”

这个类比把 RL 中几个互相配合的环节放在了一起。探索负责找到候选路径；奖励定义什么样的结果值得追求；信用分配与优化负责把这些反馈转化成下一轮更好的行为。

训练质量具体取决于：reward 是否贴近真实任务目标，exploration 是否覆盖了有用的路径，credit assignment 是否把回报传给关键动作，优化是否稳定，以及模型是否在追逐容易得分但价值低的捷径。比如，奖励只看最后答案是否碰巧命中时，训练可能偏向猜测；同时检查必要证据和任务完成过程，能让反馈更贴近我们希望强化的行为。针对奖励漏洞还需要单独检查 reward hacking。

还有一个值得区分的贡献来源：采样带来的提升与参数更新带来的提升。一次任务多试几次，会增加找到成功路径的机会；训练后的模型若在同样的采样预算下更稳定地成功，体现的是策略分布改变带来的收益。因此评估时可以固定推理预算比较训练前后，再观察增加预算后的表现，同时记录工具调用次数、成本和未见任务表现。

用原笔记的思路来概括：Agentic RL 通过与环境交互的 rollout 探索高回报轨迹，再通过策略优化提高这类轨迹及其共性决策模式的概率，把原本低概率、不稳定的潜在能力转化成更稳定的策略。 相关研究怎样支持“挖掘潜力”与“优化策略”这两层理解，见 RL 如何提升大模型的推理能力？有哪些代表性研究？。

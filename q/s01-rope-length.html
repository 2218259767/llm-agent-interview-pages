如何扩展大模型的上下文长度？PI、NTK-aware、YaRN 和 ALiBi 是什么？

追问约 5 分钟
更新于 2026-10-13
这道题接续什么是 RoPE 旋转位置编码？它和 Transformer 原始的位置编码有什么区别？

题目

如何扩展大模型的上下文长度？PI、NTK-aware、YaRN 和 ALiBi 是什么？

面试口述回答

长度扩展要解决的是，模型到了训练窗口之外，会遇到新的位置和距离分布。以 RoPE 为例，PI 最直接：按扩展倍数把位置压回原范围，但相邻位置的相位差也随之缩小。

NTK-aware 更关注频率谱，通过调整 base 等方式，让高频保留局部区分度、低频覆盖更长距离。YaRN 进一步按频段选择插值程度，并调整注意力尺度，兼顾长距离和局部信息。ALiBi 则是另一条路线，直接在注意力分数上加距离相关的线性惩罚。

做完扩展后，我会检查长文检索、跨段推理和短文本回归，再结合延迟和缓存成本判断效果。这能把位置机制的改动和实际可用的长上下文能力联系起来。

详细知识笔记展开 / 收起

1. 为什么长文本需要专门处理位置？

假设模型主要在 4K 长度训练，推理希望处理 32K 文本。更远的位置和距离会产生训练中少见的位置信号，改变注意力分布。长度扩展的目标是让模型在这些新距离上继续找到和组合有用信息。

对于 RoPE，核心是协调旋转频率与目标长度：既要覆盖更远位置，也要保留相邻 token 的区分度。

2. PI：把位置压回原来的范围

Position Interpolation（位置插值）设扩展倍数为 s=Lnew/Lolds=L_{new}/L_{old}s=Lnew​/Lold​，将旋转角缩小为原来的 1/s1/s1/s：

mθis=(ms)θi=m(θis).\frac{m\theta_i}{s}=\left(\frac{m}{s}\right)\theta_i=m\left(\frac{\theta_i}{s}\right).smθi​​=(sm​)θi​=m(sθi​​).

实现时可以缩放位置，也可以缩放旋转频率，选择其中一种即可得到相同的旋转角。例如把 4K 扩成 16K，s=4s=4s=4，新序列的第 12000 个位置以原位置 3000 的旋转角度表示。这样新位置落回较熟悉的范围，配合长文本微调即可学习扩展后的距离关系。代价是相邻位置的相位差也缩小了，局部分辨率需要通过训练适配。

3. NTK-aware：按频率调整尺度

RoPE 的频率为 θi=base−2i/d\theta_i=\mathrm{base}^{-2i/d}θi​=base−2i/d。NTK-aware 类方法通过扩大 base 等方式改变频率谱：高频部分保留较多局部分辨能力，低频部分降低旋转速度，容纳更长距离。其直觉是让不同频段承担不同尺度的位置关系。

静态方案提前确定缩放参数，动态方案根据当前长度改变缩放。采用动态方案时，缓存中历史 Key 与新 Query 的位置编码需要保持一致。

4. YaRN：分频段插值，并调整注意力尺度

YaRN 根据频段选择插值程度：对覆盖长距离的频段做较强缩放，对高频局部信息保留更多原有分辨率，中间频段平滑过渡；同时调整注意力尺度，帮助适应长度变化后的分布。

它的关键思路是差异化地处理不同频率。这样能在扩展长度和保留短距离信息之间取得更好的配合。实际应用使用相应模型配置与长文本训练配方。

5. ALiBi：直接给远距离位置加惩罚

ALiBi 是另一种位置机制。它在注意力分数中加入与距离成正比的负偏置。因果注意力中，第 hhh 个头可写为

scoreij(h)=qi⊤kjd−mh(i−j),j≤i,mh>0.\mathrm{score}^{(h)}_{ij} =\frac{q_i^\top k_j}{\sqrt d}-m_h(i-j), \qquad j\le i,\quad m_h>0.scoreij(h)​=d​qi⊤​kj​​−mh​(i−j),j≤i,mh​>0.

距离越远，惩罚越大；不同头采用不同斜率，形成不同的距离偏好。RoPE 通过旋转 Q/K 编码距离，ALiBi 通过修改分数表达距离，两者处在不同的计算位置。

6. 长度扩展后看什么？

测试可以覆盖三个方向：不同位置证据的检索、跨段信息组合与推理、原来短文本任务的表现。服务侧再测长 Prompt 的首 token 延迟、缓存显存和解码速度。这样既能知道扩展后“是否读懂”，也能知道实际使用成本。

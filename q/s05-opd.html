什么是 On-Policy Distillation（OPD）？

约 5 分钟
更新于 2026-10-13

题目

请介绍 OPD 的基本原理。它与监督微调 SFT、强化学习 RL 有什么区别，为什么说它结合了两者的特点？

面试口述回答

OPD 是同策略蒸馏：先让学生按自己的当前策略生成答案，再让教师在学生实际生成的每个前缀上提供指导，更新学生。它结合了两种优势：像 RL 一样，训练数据来自学生自己；像蒸馏一样，能获得较密集的教师监督。所以它特别关注学生真正会走到的状态，以及在这些状态下下一步该怎样调整。常见做法是用教师和学生的概率差构造训练信号，既可以看完整词表，也可以用学生实际采样 token 的概率。实践中我会重点看教师能否提供学生可吸收的新信息、评分成本，以及最终任务能力是否提升。

详细知识笔记展开 / 收起

让教师在学生真实访问的状态上指导

OPD（On-Policy Distillation，同策略蒸馏）先让学生模型按当前策略生成答案，再让教师沿着学生生成的前缀提供反馈，更新学生。这让训练覆盖学生推理时实际会遇到的状态。

离线教师蒸馏常让学生模仿教师生成的完整答案。例如教师走的是“分析 A—推导 B—结论 C”，而学生自己生成时可能先走到 B′。OPD 在这个 B′ 上查询教师的下一步判断，因而能针对学生自己的生成分布提供指导。

一次训练怎样进行

  1. 给学生问题 xxx，采样回答 y=(a,b,c,d,e)y=(a,b,c,d,e)y=(a,b,c,d,e)。
  2. 在每个学生前缀上查询教师，例如生成 ccc 的位置使用上下文 (x,a,b)(x,a,b)(x,a,b)。
  3. 比较学生与教师对下一 token 的概率判断，形成逐 token 监督。
  4. 更新学生策略，再用新的学生继续采样。

令 st=(x,y<t)s_t=(x,y_{<t})st​=(x,y<t​)，一种常见目标是最小化反向 KL：

DKL(πθ∥πT∣st)=∑vπθ(v∣st)log⁡πθ(v∣st)πT(v∣st).D_{\mathrm{KL}}(\pi_\theta\|\pi_T\mid s_t)=\sum_v\pi_\theta(v\mid s_t)\log\frac{\pi_\theta(v\mid s_t)}{\pi_T(v\mid s_t)}.DKL​(πθ​∥πT​∣st​)=v∑​πθ​(v∣st​)logπT​(v∣st​)πθ​(v∣st​)​.

vvv 遍历词表；πθ\pi_\thetaπθ​ 是学生，πT\pi_TπT​ 是教师。它衡量学生在自身访问的前缀上，与教师下一步选择的差异。

全词表监督与采样 token 监督

若使用完整词表求和，需要教师与学生在该词表上的概率分布。也可以利用学生采样的 token 估计期望：

DKL(πθ∥πT∣st)=Ea∼πθ[log⁡πθ(a∣st)−log⁡πT(a∣st)].D_{\mathrm{KL}}(\pi_\theta\|\pi_T\mid s_t) =\mathbb E_{a\sim\pi_\theta}\left[\log\pi_\theta(a\mid s_t)-\log\pi_T(a\mid s_t)\right].DKL​(πθ​∥πT​∣st​)=Ea∼πθ​​[logπθ​(a∣st​)−logπT​(a∣st​)].

Thinking Machines 的公开实现查询教师对学生已采样 token 的 log probability，将教师与学生的对数概率差作为逐 token 优势，再通过策略梯度式更新学生。这里要一起设计采样分布、优势的梯度处理和新旧策略比率。对齐 token 概率时，教师和学生需要兼容的 token 表示。

SFT、结果奖励 RL 与 OPD 的关系

方法 训练轨迹 典型反馈 主要价值
SFT / 离线蒸馏 人工或教师示范 每个目标 token 的监督 高效学习已有优质示范
结果奖励 RL 学生自己探索 完成任务后的奖励 围绕真实目标改进行动策略
概率监督 OPD 学生自己生成 教师在学生前缀上的逐 token 反馈 在贴近学生的状态上获得密集指导

OPD 的吸引力就在于这两点：数据与学生当前策略相关，教师反馈又较密集。 在实际任务中，还应把学生采样、教师评分和参数更新都计入训练成本。

实践判断与后续追问

教师选择同时考虑目标能力、与学生的局部分布兼容性以及评分成本。学生与教师差距较大时，可先用教师答案做一段 SFT 冷启动，再进入 OPD；长轨迹可按位置检查教师反馈质量，并与最终任务效果一起评价。

教师仅提供文本时，可以采用 黑盒 OPD / GAD；关于教师选择、冷启动和长轨迹诊断，见 OPD 教师选择与训练诊断。此外，同策略自蒸馏可以让教师端看到标准答案等额外信息，用带额外信息的分布指导仅看到原问题的学生。

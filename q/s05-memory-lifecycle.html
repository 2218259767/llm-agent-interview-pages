Agent Memory 是什么？如何设计写入、检索、更新与遗忘？

约 6 分钟
更新于 2026-10-13

题目

Agent Memory 是什么？如何设计写入、检索、更新与遗忘？

面试口述回答

Agent Memory 是让 Agent 在多轮和跨会话任务中持续维护状态的机制，可以保存用户偏好、任务进度、事实和执行经验。我会围绕五个环节设计：写入时挑选有长期价值且有依据的信息；存储时按事实、事件和经验选择结构；检索时结合任务、时间与主体取回相关内容；更新时处理新旧事实和生效范围；最后设计过期、纠错和删除规则。这里很关键的一点是保留来源和时间，让长期状态可以被核查和修正。系统起步可以使用结构化笔记，随着任务复杂度再增加向量或图检索，并持续用跨会话任务评估效果。

详细知识笔记展开 / 收起

定义：让 Agent 持续维护并使用长期状态

Agent Memory 是 Agent 在多轮交互、长期任务和多个会话之间保存、组织和利用信息的机制。记忆可以是用户偏好、任务进度、带时间的事实、执行经验，或者可复用的技能与程序。

上下文窗口是模型当前这一步能直接使用的工作区；持久记忆保存在窗口外，按任务需要取回；上下文工程负责组合当前指令、状态、工具结果与检索内容。RAG 提供外部知识检索能力，而 Agent Memory 还关注从交互经历中形成、更新和使用长期状态。

写入什么：提炼有持续价值的信息

写入前判断信息的用途与依据：稳定偏好、任务阶段、明确决策、已验证经验通常值得保存；一次性闲聊和重复工具输出可以省略。区分用户明确陈述、工具观察和模型推断，为记忆附上主体、来源、发生时间、适用范围和证据引用。

例如用户从“每周三下午开会”改为“从下月起改到周五”，记忆应保存生效时间，使当前安排与下月安排都能正确查询。

怎么组织：选择适合查询和更新的表示

记忆内容 适合的表示 主要用途
原始经历与证据 对话片段、事件日志 回查事实经过
用户偏好与关键事实 结构化字段、键值记录 精确读取与更新
长任务进度 摘要、待办、持久笔记 跨会话接续工作
实体关系与时间变化 关系图、时间事件 多跳与时间查询
执行经验 反思笔记、操作程序 复用成功方法与失败教训

可以同时保存结构化摘要和原始证据引用：摘要便于快速检索，引用便于需要细节时回查。

何时检索：按当前任务选择上下文

开始任务时读取相关身份和任务状态，遇到具体实体或历史依赖时按需检索。先用主体、权限、时间、任务等元数据过滤，再结合关键词、语义召回和重排，挑选最相关且仍有效的信息。

检索结果进入上下文时，应保留来源与必要时间信息。精确字段、否定、更正和版本切换都适合显式处理。长历史可以压缩为结构化笔记，并在需要时沿引用取回原文。

如何更新与遗忘？

新信息到来后，判断是新增事实、补充细节、替换旧值，还是撤销旧判断。对冲突信息记录生效时间、证据和版本，使查询能选中适用状态。

遗忘也需要明确动作：临时移出上下文、从可检索索引淘汰、从持久存储删除。对过期状态设置有效期，对用户要求删除的信息同步清理索引和衍生摘要，防止后续整理又将旧记录带回。

常见技术路线怎样理解？

路线与代表工作 核心做法
经历与反思：Generative Agents、Reflexion Generative Agents 记录观察、提炼反思，再通过检索支持规划；Reflexion 将任务反馈整理成经验文本，供下一次尝试使用。
技能记忆：Voyager 将任务中形成的可复用技能保存为程序库。后续任务可以检索并组合已有技能，逐步积累行动能力。
分层上下文管理：MemGPT 将工作上下文与外部存储分层，按需换入、换出信息。它借用操作系统虚拟内存的思路，管理模型当前可见内容。
模型级长期记忆：LongMem 冻结原语言模型作为记忆编码器，缓存过去的上下文表征，再训练一个残差侧网络检索和读取这些记忆。它把长期记忆的使用能力融入模型结构和训练。
图检索：HippoRAG 结合 LLM、知识图谱和 Personalized PageRank，在与问题相关的实体之间传播检索信号。图中的关联帮助系统找到分散在多份材料里的多跳证据。
动态笔记组织：A-MEM 为新记忆生成包含上下文、关键词和标签的结构化笔记，并自动关联已有记忆。新笔记还可以促使旧笔记的描述和属性更新，形成持续演化的知识网络。
记忆抽取与整合：Mem0 从持续对话中抽取有用信息，与已有记忆整合，再按问题检索，重点兼顾长期一致性、token 成本和延迟。论文的图记忆扩展进一步表示记忆之间的关系。
时间图谱：Zep 通过 Graphiti 把对话与结构化业务数据组织进带时间的知识图谱，并保留关系的历史变化。这样能按任务需要取回当前状态或过去某个阶段的事实。

工程上可先用结构化文件或数据库把写入、读取、更新流程跑清楚，再按检索需求增加向量或图索引。同时建立跨会话测试，衡量记忆对任务成功率、时延和成本的影响。

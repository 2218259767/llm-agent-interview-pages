Qwen3 去掉 QKV-bias、引入 QK-Norm，具体是什么意思？

追问约 4 分钟
更新于 2026-10-13
这道题接续Qwen3 相比于 Qwen2.5 和 Qwen2 有哪些改进？

题目

Qwen3 去掉 QKV-bias、引入 QK-Norm，具体是什么意思？

面试口述回答

这两个改动来自 Qwen3 的注意力结构。去掉 QKV-bias，就是把三个投影从 XW 加 b 改成 XW，保留权重学习，去掉对所有 token 共用的额外偏移。

QK-Norm 则是在算注意力点积之前，对每个头的 Q、K 做 RMSNorm。因为点积会受 Q、K 模长影响，模长过大会把 Softmax 推向很尖的分布，使优化变难。归一化能控制这个尺度，再结合可学习缩放和 RoPE，完成内容与位置匹配。

所以我理解，Qwen3 的这个设计是在简化投影的同时，把注意力数值尺度显式管理起来，帮助大规模训练更稳定。

详细知识笔记展开 / 收起

1. 这道追问从哪里来？

在介绍 Qwen3 相比 Qwen2、Qwen2.5 的架构变化时，会提到两个改动：Q、K、V 投影去掉偏置，并在注意力点积前加入 QK-Norm。前者调整线性投影，后者直接控制 Q、K 的数值尺度。Qwen3 报告将这组设计用于提高训练稳定性。

2. 去掉 QKV-bias 是什么？

输入隐藏状态为 XXX，有偏置的投影为

Q=XWQ+bQ,K=XWK+bK,V=XWV+bV.Q=XW_Q+b_Q,\qquad K=XW_K+b_K,\qquad V=XW_V+b_V.Q=XWQ​+bQ​,K=XWK​+bK​,V=XWV​+bV​.

去掉偏置后变成

Q=XWQ,K=XWK,V=XWV.Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V.Q=XWQ​,K=XWK​,V=XWV​.

三个投影层仍会学习各自的权重矩阵，只是输出不再额外叠加一组对所有 token 共用的偏移量。这个改动让投影结构更简洁，并减少少量参数。

3. QK-Norm 是什么？

QK-Norm 在计算 Attention Score 之前，对 Query、Key 做归一化。Qwen3 使用每个头内的 RMSNorm，形式可写为

RMSNorm⁡(q)=q1dh∑i=1dhqi2+ϵ⊙γ.\operatorname{RMSNorm}(q) =\frac{q}{\sqrt{\frac{1}{d_h}\sum_{i=1}^{d_h}q_i^2+\epsilon}}\odot\gamma.RMSNorm(q)=dh​1​∑i=1dh​​qi2​+ϵ​q​⊙γ.

dhd_hdh​ 是头维度，γ\gammaγ 是可学习缩放参数。Q、K 经过归一化后再结合 RoPE 做位置旋转，送入注意力计算：

q^m=RmRMSNorm⁡(qm),k^n=RnRMSNorm⁡(kn),amn=softmax⁡n(q^m⊤k^ndh).\hat q_m=R_m\operatorname{RMSNorm}(q_m),\qquad \hat k_n=R_n\operatorname{RMSNorm}(k_n),\qquad a_{mn}=\operatorname{softmax}_n\left(\frac{\hat q_m^\top\hat k_n}{\sqrt{d_h}}\right).q^​m​=Rm​RMSNorm(qm​),k^n​=Rn​RMSNorm(kn​),amn​=softmaxn​(dh​​q^​m⊤​k^n​​).

4. 为什么能帮助训练稳定？

点积大小受向量模长影响。训练中 Q/K 模长持续增大，会拉大注意力分数差，使 Softmax 分布过于尖锐，分数对梯度的响应变弱。QK-Norm 把每个头的尺度显式控制住，让方向上的匹配和可学习缩放共同决定注意力强弱。

例如两个头关注的内容不同，但某个头的 Q/K 范数增长过快，它可能仅凭数值尺度形成极端分布。归一化使各头的尺度更可控，便于长期优化。

5. QK-Norm 与 RoPE 怎样配合？

QK-Norm 管理向量尺度，RoPE 注入位置关系。RoPE 旋转保持模长，因此二者可以自然组合：先得到尺度可控的 Q/K，再通过旋转表达相对距离。解释这组设计时，重点是投影简化和注意力尺度管理。

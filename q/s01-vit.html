视觉与多模态模型／ViT、CLIP 与视觉语言模型

请介绍一下 ViT（Vision Transformer）。

约 3 分钟
更新于 2026-10-13

题目

请介绍一下 ViT（Vision Transformer）。

面试口述回答

ViT 的核心是把图像变成序列，再用 Transformer 来处理。比如一张 224×224 的图切成 16×16 的 Patch，会得到 196 个图块；每块通过线性映射得到向量，加上位置编码后输入 Transformer Encoder。分类任务通常用 CLS token 汇总信息。和 CNN 相比，ViT 的局部结构先验更少，但全局自注意力能直接建模远距离图块关系，大规模预训练对它很重要。对于多模态大模型，ViT 还有一个很自然的优势：输出就是 Patch 特征序列，经过连接层后便能作为视觉 token 交给语言模型。

详细知识笔记展开 / 收起

核心思想：把图像表示为 Patch 序列

ViT 将图像切成固定大小的图块（Patch），把每个图块映射成向量，再用 Transformer Encoder 建模图块之间的关系。它将序列建模方法应用到视觉任务，是许多视觉编码器和多模态系统的重要基础。

一张图片经过哪些步骤？

假设输入图像为 224×224224\times224224×224，Patch 大小为 16×1616\times1616×16，那么会得到 14×14=19614\times14=19614×14=196 个 Patch。

  1. 切块与映射：每块像素展平后，经可学习线性映射得到 DDD 维 Patch Embedding。
  2. 加入位置信息：给 Patch 表示加上位置编码，记录各图块的空间布局；经典分类 ViT 还在开头加入一个可学习的 [CLS] token。
  3. Transformer Encoder：通过多头自注意力、前馈网络、归一化与残差连接提取视觉表示。
  4. 输出任务结果：分类时使用 [CLS] 的最终表示送入分类头；作为多模态视觉编码器时，可保留各 Patch 的特征用于后续连接模块。

与 CNN 的主要区别：归纳偏置

CNN 的局部卷积与权重共享带来局部性、平移等变性等结构先验，小数据下往往更容易学习。ViT 的全局自注意力从较早层即可建立远距离图块关系，更多依靠数据学习视觉结构，因此原始 ViT 特别受益于大规模预训练。

Patch 数越多，保留的空间细节越丰富，但全局注意力中两两交互的开销也随之增加。若图块数为 NNN，注意力部分的算术开销约为 O(N2D)O(N^2D)O(N2D)。

为什么它适合多模态模型？

ViT 输出的 Patch 特征天然是向量序列，便于通过 Projector 接入语言模型。CLIP 可以用 ViT 做图像编码器，LLaVA 等模型再使用这类视觉特征完成图文问答。

常见延伸包括 Swin 的局部窗口与层级结构，以及 MAE 的掩码图像自监督学习：前者调整视觉建模与计算方式，后者探索高效的视觉预训练任务。

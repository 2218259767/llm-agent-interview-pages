什么是 DAPO？相比 GRPO 有哪些改进？

约 4 分钟
更新于 2026-10-13

题目

请介绍 DAPO 的基本思路，以及它针对长推理训练提出的四项主要改进。

面试口述回答

DAPO 是面向长推理训练的一套组相对策略优化改进，主要有四点。第一，Clip-Higher 把上下裁剪解耦，提高上界，给有价值的低概率 token 更多探索空间。第二，动态采样过滤组内全对或全错的题，再补足有效样本。第三，损失按全批次的有效 token 平均，让长回答中的 token 获得一致的基本权重。第四，对接近长度上限的回答使用软惩罚，减轻截断带来的奖励噪声。我理解它是围绕训练中真正影响收敛的几个环节做系统改进，因此评估时会把正确率、熵、长度和总采样成本放在一起看。

详细知识笔记展开 / 收起

DAPO 解决的是什么问题

DAPO（Decoupled Clip and Dynamic Sampling Policy Optimization）是在组相对策略优化基础上，面向大规模长推理训练改进采样、裁剪、损失归约和奖励处理的方法。原笔记中的四个关键词可以对应四个训练问题：探索过早收缩、无效采样组、长短回答权重以及截断奖励噪声。

1. Clip-Higher：给探索留出更大的更新空间

对新旧策略概率比 ρ\rhoρ 使用上下界不同的裁剪区间：

clip⁡(ρ,1−εlow,1+εhigh).\operatorname{clip}(\rho,1-\varepsilon_{\mathrm{low}},1+\varepsilon_{\mathrm{high}}).clip(ρ,1−εlow​,1+εhigh​).

论文采用过 εlow=0.2\varepsilon_{\mathrm{low}}=0.2εlow​=0.2、εhigh=0.28\varepsilon_{\mathrm{high}}=0.28εhigh​=0.28 的配置。提高上界，可以让正优势、原本概率较低的 token 获得更大的概率提升空间，缓解策略熵过早下降。实际配置需要结合熵、裁剪比例和效果调整。

2. Dynamic Sampling：补足有学习信号的组

二值奖励下，如果同一问题的所有回答全对或全错，组内优势为零。DAPO 过滤这些组并继续采样，直到收集到足够的有效问题组。这样一个更新批次中，有区分度的样本比例更高；总成本同时要包含补采样消耗。

3. Token-level Loss：调整长短回答的权重

设 ℓi,t\ell_{i,t}ℓi,t​ 是单个 token 的策略损失。原始 GRPO 常用“先对每个回答平均，再对回答平均”；DAPO 按整个批次的有效 token 平均：

Lseq=1G∑i1Ti∑tℓi,t,Ltoken=∑i∑tℓi,t∑iTi.\mathcal L_{\mathrm{seq}}=\frac1G\sum_i\frac1{T_i}\sum_t\ell_{i,t},\qquad \mathcal L_{\mathrm{token}}=\frac{\sum_i\sum_t\ell_{i,t}}{\sum_i T_i}.Lseq​=G1​i∑​Ti​1​t∑​ℓi,t​,Ltoken​=∑i​Ti​∑i​∑t​ℓi,t​​.

前者让每条回答占相近总权重；后者让每个有效 token 的基本权重一致，因而更长的回答会获得更大的总权重。这是理解 DAPO 长推理训练行为的重要细节。

4. Overlong Reward Shaping：更平滑地处理超长回答

生成到长度上限时，回答可能因截断而失去完整答案。DAPO 研究了对这类样本的处理，并引入软长度惩罚：在接近最大长度的一段区间内逐渐增加惩罚，让模型获得更连续的反馈。

令最大长度为 Lmax⁡L_{\max}Lmax​、惩罚窗口为 LcacheL_{\mathrm{cache}}Lcache​，一个对应的分段形式是：

rlength(T)={0,T≤Lmax⁡−Lcache,Lmax⁡−Lcache−TLcache,Lmax⁡−Lcache<T≤Lmax⁡,−1,T>Lmax⁡.r_{\mathrm{length}}(T)=\begin{cases} 0,&T\le L_{\max}-L_{\mathrm{cache}},\\ \dfrac{L_{\max}-L_{\mathrm{cache}}-T}{L_{\mathrm{cache}}},&L_{\max}-L_{\mathrm{cache}}<T\le L_{\max},\\ -1,&T>L_{\max}. \end{cases}rlength​(T)=⎩⎨⎧​0,Lcache​Lmax​−Lcache​−T​,−1,​T≤Lmax​−Lcache​,Lmax​−Lcache​<T≤Lmax​,T>Lmax​.​

怎样理解这套改进

DAPO 的价值在于把采样信号、探索和长序列优化一起考虑。其论文的长推理配置还移除了 KL 项。比较训练方案时，可以同时记录正确率、有效组比例、输出长度、策略熵以及总生成 token 成本，观察四项机制如何共同影响训练。

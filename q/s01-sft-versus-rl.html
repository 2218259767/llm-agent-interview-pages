SFT 与 RL 在学习信号、探索和适用任务上如何分工？

题目

SFT 与 RL 在学习信号、探索和适用任务上如何分工？

SPEAK WITH CLARITY · 面试表达

面试口述回答

SFT 从示范中提高目标行为的似然，RL 根据交互或采样反馈优化期望回报。前者适合已有高质量示范、需要快速建立行为格式的任务，后者适合结果可评价但最佳路径难逐步标注的任务。二者都能影响知识、推理和行为，不能简单说 SFT 只教表面、RL 只教真正做事。我的选型会看示范成本、奖励可靠性、探索空间和回归风险；先 SFT 再 RL 是常见配方，但不是理论上的必经顺序。

详细知识笔记展开 / 收起

学习信号不同

SFT 使用示范序列，在给定上下文下提高目标 token 的条件概率：

LSFT=−∑tlog⁡πθ(yt∣x,y<t).L_{\mathrm{SFT}}=-\sum_t\log\pi_\theta(y_t\mid x,y_{<t}).LSFT​=−t∑​logπθ​(yt​∣x,y<t​).

它适合学习格式、语言风格、工具调用模式和示范中的知识，但会学习示范中不必要的细节，也受示范覆盖限制。

RL 根据策略采样的输出获得回报，再调整行为概率。奖励可以来自规则、环境、偏好模型或其他反馈。它允许比较多种路径的结果，适合可验证推理或多步决策，但采样成本、奖励设计、方差和稳定性更难处理。

不是简单的能力高低关系

SFT 并不只会逐字记忆，RL 也不会自动产生可靠的全新知识。能力变化同时受基座、数据、奖励、探索预算和评价协议影响。对缺乏基础行为的模型，SFT 常是实用起点；有些研究会直接从 base model 做 RL，因此“必须先 SFT”不是定义要求。

项目中如何选择

若目标可以提供高质量示范，先用 SFT 建立可用基线。若答案路径很多但结果可判定，可考虑 RL；若只有离线成对偏好，DPO 是另一种选择。所有方案都应在同一任务划分与计算预算下比较，并监测奖励上升但真实成功率不升的情况。

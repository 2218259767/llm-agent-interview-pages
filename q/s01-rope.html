基础模型架构／位置编码与长上下文

什么是 RoPE 旋转位置编码？它和 Transformer 原始的位置编码有什么区别？

约 4 分钟
更新于 2026-10-13

题目

什么是 RoPE 旋转位置编码？它和 Transformer 原始的位置编码有什么区别？

面试口述回答

RoPE 是旋转位置编码。原始 Transformer 把位置向量加在输入 Embedding 上，RoPE 则在每层 Attention 中，按 token 位置对 Query 和 Key 做旋转。

具体来说，它把通道两两配成二维向量，每对使用不同频率，位置 m 对应旋转 mθ。位置 m 的 Query 和位置 n 的 Key 做点积时，两个旋转矩阵合并成相对旋转 R_(n−m)，所以分数既包含内容匹配，也包含两个 token 的相对距离。

这种设计把距离直接融进了注意力关系，旋转还保持向量模长，也不需要学习一张位置表。标准用法在 Q、K 上加位置，V 保留为信息载体。做更长上下文时，通常再配合频率调整和长文本训练，让模型适应新的距离范围。

详细知识笔记展开 / 收起

1. RoPE 把位置变成 Q、K 的旋转角度

RoPE（Rotary Position Embedding）通过按位置旋转 Query 和 Key，让注意力分数包含相对位置信息。原始 Transformer 将位置向量加到输入 Embedding；RoPE 则作用于各层 Attention 的 Q、K。

可以把每两个通道想象成一个二维箭头。位置为 mmm 时，把箭头旋转 mθm\thetamθ，位置越靠后，旋转角度越大。原向量的内容决定箭头原本的方向，位置决定额外旋转多少。

2. 从二维旋转理解公式

对二维向量 q=(q0,q1)⊤q=(q_0,q_1)^\topq=(q0​,q1​)⊤，旋转为

f(q,m)=R(mθ)q,R(mθ)=(cos⁡(mθ)−sin⁡(mθ)sin⁡(mθ)cos⁡(mθ)).f(q,m)=R(m\theta)q, \qquad R(m\theta)=\begin{pmatrix} \cos(m\theta)&-\sin(m\theta)\\ \sin(m\theta)&\cos(m\theta) \end{pmatrix}.f(q,m)=R(mθ)q,R(mθ)=(cos(mθ)sin(mθ)​−sin(mθ)cos(mθ)​).

用复数表示，将 q0+iq1q_0+iq_1q0​+iq1​ 乘以 eimθe^{im\theta}eimθ 就完成同一旋转。mmm 是 token 的绝对位置索引，θ\thetaθ 是这一对通道使用的旋转频率。

对于 ddd 维向量，将通道两两配对，每对采用一个频率 θi=base−2i/d\theta_i=\mathrm{base}^{-2i/d}θi​=base−2i/d。高频旋转更快，对较短距离变化敏感；低频旋转更慢，覆盖较长距离。各二维旋转组合成块对角矩阵 RmR_mRm​。

3. 为什么会得到相对位置信息？

位置 mmm 的 Query 旋转为 RmqR_mqRm​q，位置 nnn 的 Key 旋转为 RnkR_nkRn​k。采用上面的正向旋转约定：

(Rmq)⊤(Rnk)=q⊤Rm⊤Rnk=q⊤Rn−mk.(R_mq)^\top(R_nk) =q^\top R_m^\top R_nk =q^\top R_{n-m}k.(Rm​q)⊤(Rn​k)=q⊤Rm⊤​Rn​k=q⊤Rn−m​k.

位置因素因此以距离 n−mn-mn−m 的形式进入分数，同时分数继续表达 q、k 的内容匹配。例如保持两个内容向量相同，把它们从位置 3、5 一起移到 103、105，位置差仍为 2，对应旋转关系相同。

4. 与原始位置编码相比，优势在哪里？

维度 原始正弦位置编码 RoPE
作用位置 输入 Embedding 各层 Attention 的 Q、K
操作 加位置向量 按位置旋转通道对
位置信息 显式绝对位置表示 绝对位置旋转，在点积中形成相对距离
参数 固定函数生成 固定频率生成旋转，无需学习位置表

旋转保持向量模长，并把位置信息直接融入注意力匹配。标准 RoPE 保留 V 作为被加权聚合的信息载体；Q/K 上的旋转负责决定各位置该如何关联。

5. RoPE 与长上下文

RoPE 的旋转规则可计算新位置，具有良好的长度扩展基础。实际扩展到远超训练窗口时，模型会遇到新的相位组合，需要配合 PI、NTK-aware 或 YaRN 等方法调整频率，并通过长文本继续训练适配。下一题单独讨论这些扩展方法。
